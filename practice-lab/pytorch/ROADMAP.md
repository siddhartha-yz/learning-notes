## 目标与起点

用户确认：Python 基础尚可，张量、形状变换、自动求导从头练；新概念先阅读与预测，随后以独立实现为主。本轮落地第一阶段，之后根据作答反馈调整。

“熟练”应体现为：能在新输入形状下正确实现、说清每个轴与运算对应的含义、定位错误、隔一段时间仍能重写并完成迁移。通过一道题只说明这次提交满足要求，不能证明已经炉火纯青。第一版只记录通过与练习证据，不伪造熟练度评分。

## 进阶路线

| 阶段 | 模型语境与核心题方向 | 进入下一阶段前需要能做什么 |
| --- | --- | --- |
| 01 张量是数据的表示（本轮实现） | 建立批次；保留样本轴展平图像；逐特征中心化；逐样本类别概率；索引真实类别；排除 padding 的 token 平均损失 | 写明每个轴的含义，处理 B=1 与 B≠D，区分归约、广播、索引 |
| 02 梯度是计算依赖 | 标量回归梯度；mean 与 sum 的梯度尺度；共享参数的两条梯度路径；detach 与 no_grad 对照 | 预测哪些变量有梯度，区分数值相同与梯度路径相同 |
| 03 从目标函数到一次训练 | 线性回归一步更新；稳定的分类损失；梯度清零；训练／验证分离 | 独立写一个完整小训练循环，检查参数确实改变，解释更新顺序 |
| 04 Module 表示模型结构 | 手写仿射层对照 nn.Linear；参数注册；MLP；共享层；state_dict 往返 | 区分参数、激活和缓冲区，核对形状和参数量 |
| 05 图像模型与轴 | 小型互相关；池化；按通道统计；训练／推理模式；残差连接 | 解释 NCHW 中每个轴，识别错误广播与错位的残差相加 |
| 06 序列表示与批处理 | token 索引与 embedding；batch/time 换轴；标签错位；padding mask | 独立构造 X 与下一 token 的 Y，保持样本与时间对应 |
| 07 RNN 成为一段明确计算 | 单步 RNN；沿时间展开；共享参数；隐藏状态与输出；多层与多时间步对照 | 从公式写循环，用微型例子跟踪每一步的状态及同一份参数 |
| 08 RNN 训练与长期依赖 | 完整／截断 BPTT；梯度裁剪；GRU 门控；小序列综合训练 | 区分状态传递与梯度截断，用实际梯度证据解释 detach 的影响 |

每个后续阶段先设计少量核心题，再添加能改变推理任务的变式与纠错题。不靠换随机数扩充题目数量。CNN 与训练状态的部分可在 RNN 主线形成后补强；按反馈调整顺序，避免为了目录完整拖延真正的理解目标。

## 第一阶段：六题，三小节

1. 张量表示：从一批样本构造特征和标签；把图像展平且保留 batch。
2. 轴与广播：按特征中心化；把每个样本的 logits 转成类别概率。
3. 索引与序列：取得各样本真实类别的概率；只对有效 token 计算平均损失。

每题包含：默认可见的零基础概念与必要 API 语法教学、逐行讲解的可编辑运行例子、修改观察任务，然后是明确函数签名与输入输出契约、运行前预测、独立实现、可执行测试、简短解释。基础教学不等于泄露答案，不能藏在提示里或要求学习者先自行查文档；额外解题提示仍按需提供。每道核心题预留20–40分钟。测试覆盖不同形状、B=1、轴尺寸相等与不等、非连续输入（题目契约允许时）、边界数值和有区分力的反例。不会隐藏未说明的知识要求。

后续复习设计方向：提示后通过→重新独立实现→有意义变式→隔日复做。间隔复习队列与自动熟练度判断不属于本轮已经完成的功能。

## 判题原则

本地运行 PyTorch，比较真实输出的形状、dtype、数值与输入是否被意外改动；失败时给具体样例证据。Agent 只判断预测与解释是否符合本题，不替代执行测试，不追加题外要求。通过后不追加拓展追问。

PyTorch 执行必须隔离于桌面应用、密钥、笔记和宿主机 Home。CPU 小张量即可完成第一阶段；运行与提交日志记录代码、输入预测、测试结果、提示使用情况和模型评审，不把测试模拟数据混作用户记录。
