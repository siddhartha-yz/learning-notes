# PyTorch 练习：第一阶段

完整分析与进阶路线见 [ROADMAP.md](./ROADMAP.md)。当前落地 6 题，分“张量表示”“轴与广播”“索引与序列”三小节，每小节两道核心题。自动求导、训练循环、模型结构与 RNN 是后续路线，本版未开放。

## 在桌面应用中练习

1. 启动 `practice-lab/launch.sh`，选择 **PyTorch · 模型的可执行表示**。
2. 选择能力阶段和题目，默认进入“先学 · 讲解与实验”：阅读概念和逐行语法说明，直接运行并修改例子，在下方观察真实输出。无需预测、API 或提交；之后点击“进入独立练习”，阅读约定并写下预测。
3. 在代码区独立实现函数。支持多行编辑、Tab 四空格缩进、Enter 延续缩进；这是轻量编辑器，不是完整 IDE。
4. 点击“运行测试”，查看每个测试结果。失败显示输入、预期和实际差异。运行不调用 API。
5. 填写简短解释。若预测不对，在解释中说明修正；初始预测不会作为必须一次答对的门槛。
6. 点击“提交代码与解释给 Agent”。本地测试不通过、代码修改后没有重跑、缺少解释时，不调用模型。模型只评审本题理解，不给题外作业。

基础语法与 API 用法默认在教学页展示，随时可返回查看。左侧提示只提供额外解题帮助。教学例子的修改也自动保存，可单独恢复原例；运行例子不会改变测试结果或题目进度。代码、预测、解释与提示层级作为本机草稿自动保存，切题或重启后恢复；恢复草稿后须重新运行测试，避免复用过期结果。重做会清除当前草稿并恢复函数签名，历史通过状态仍保留。

“阅读路线与关联笔记”可查看完整路线与对应原始笔记。旧笔记是背景资料，不自动作为所有技术陈述的真值；评分以明确题目契约和真实运行结果为准。

## 运行环境

开发机已安装独立 CPU PyTorch 环境：`~/.local/share/learning-notes-lab/torch-runtime`，当前测试版本 `torch==2.14.0+cpu`，无 GPU 依赖。首次安装或在新电脑部署：

```bash
./practice-lab/setup-torch.sh
```

脚本需要 `uv` 和受该 PyTorch wheel 支持的系统 Python；本机使用 Python 3.14。可用 `LEARNING_LAB_TORCH_RUNTIME` 指向兼容的独立虚拟环境。本版默认环境的 Python 链接到系统 `/usr/bin/python3`；若使用自行下载的 Python，需要使该解释器在隔离环境中也可访问。

桌面进程使用系统 GTK，只有独立子进程加载 torch。bubblewrap 只挂载工具运行库、PyTorch 虚拟环境、提交代码、判题资源和临时工作目录，不挂载宿主机 Home、笔记仓库与 API 凭据；无网络。单次运行限时25秒，CPU时间20秒、虚拟地址空间4 GiB、文件大小1 MiB；输出限长。第一阶段仅用小型 CPU 张量。

这是个人练习环境，不是面向恶意提交者的竞赛判题平台：测试与学生函数在同一隔离进程中运行，题库和参考回归实现也在本地可读，不宣称能够防作弊。它的作用是检验真实学习中的错误，并将代码执行与个人文件隔离。

## 记录

本机草稿位于 `~/.local/state/learning-notes-lab/pytorch-drafts/`（遵循 XDG_STATE_HOME）。每次运行与正式提交分别在 `practice-lab/attempts/日期/` 保存 `pytorch_tutorial_run`、`pytorch_run` 或 `pytorch_submission`：代码、当次运行前预测、解释、题目快照、测试输入输出、提示层级与评审状态。下次 `note` 可一并上传。

运行通过仅代表本地测试通过；`reviewed` 且 `passed=true` 的正式提交才代表本题通过。API 未配置或失败会保留提交状态。失败预测可以在解释中修正，不篡改已经记录的运行前预测。密钥不进入这些记录。

本版尚未提供独立变式队列、间隔复习调度、真实熟练度评分、代码语法高亮或调试器。基础题的形状与数值反例已经纳入当前可运行测试，后续变式应改变需要推理的条件，而非单纯换数字。

## 验证

```bash
python3 -m unittest discover -s practice-lab -v
python3 practice-lab/ui_smoke.py
python3 practice-lab/pytorch_ui_smoke.py
```

自动测试包含真实 PyTorch 正确实现、典型错误、原地修改、语法错误、隔离访问限制。未安装独立 torch 环境时 PyTorch 回归测试会明确跳过，不能将跳过视为验证通过。GTK 测试使用临时草稿和进度、模拟 API，不消耗模型额度、不污染学生记录。
