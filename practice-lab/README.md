## 启动

在仓库根目录执行：

```bash
./practice-lab/launch.sh
```

Ubuntu / Debian 依赖（开发电脑已有）：

```bash
sudo apt install python3-gi gir1.2-gtk-3.0 bubblewrap
```

需要图形桌面及允许 bubblewrap 用户命名空间的 Linux。隔离不可用时拒绝执行，不降级为宿主机终端。

可选：执行 `python3 practice-lab/install-launcher.py`，在应用菜单搜索“实践工坊”启动。仓库移动后重新执行可更新入口路径。

## 使用

1. 按日期选择题目，阅读任务；可打开对应笔记或查看提示。左侧滚动条可查看较长任务的全部步骤。
2. 输入命令并按 Enter，查看真实命令输出。当前目录与临时文件修改会延续。
3. `more` 进入分页后，在命令输入框按 Space 翻页，按 q 退出；只有已经展示的页面进入提交记录。
4. 填写观察与解释，在 API 设置中配置 HTTPS Base URL、模型名和密钥。
5. 提交给 Agent。本地检查和模型评审都满足才通过；通过后显示固定完成提示和下一题入口，不追加拓展问题。未通过时只反馈本题缺失项。

Base URL 使用兼容 OpenAI Chat Completions 的服务地址，保留服务商所需前缀（如 `/v1`），应用追加 `/chat/completions`。模型需要支持 `messages` 和文本 JSON 输出；不强制 JSON schema 功能。请求格式参考 [官方 API 文档](https://developers.openai.com/api/reference/resources/chat)。

API 设置默认勾选“在本机记住密钥”，保存一次后重启自动加载。地址和模型保存在 `$XDG_STATE_HOME/learning-notes-lab/api.json`（默认 `~/.local/state/learning-notes-lab/api.json`），密钥保存在同目录 `credentials.json`，权限为 `0600`（仅当前用户可读写）。这是本机明文文件，不是加密钥匙串；文件位于仓库外，不提交到 Git，也不进入练习环境或日志。密钥与 Base URL 关联，地址不匹配时不自动加载。取消勾选并保存，或清空密钥再保存，会删除已保存的密钥。也可通过 `LEARNING_LAB_API_KEY` 环境变量提供密钥，环境变量优先。进度继续保存在同目录 `progress.json`。

## 执行范围

26.9.3 支持 `ls`、`cd`、`pwd`，练习文件只读。26.9.4 增加 `mkdir`、`touch`、`cat`、`more`、`cp`、`mv`、`rm`，只允许在隔离临时 Home 中修改文件，`/datasets` 保持只读。

26.9.6 使用独立可写环境，支持 `which`、`find`、`grep`、`wc`、`echo`、`tail`，允许连接本章支持命令的管道、`>` / `>>`，以及反引号中的 `pwd`。管道任一阶段失败会返回失败状态，最终生成的摘要会逐字检查。`find` 仅用于查找，不开放执行命令或删除文件的选项。

每次输入一条命令或本章支持的管道。Bash 处理相对路径、绝对路径、`~`、引号和通配符；带引号的 `'*'` 是字面量，不会展开。26.9.3 / 26.9.4 不支持管道和重定向；所有章节均不支持任意变量、通用命令替换、Tab 补全或通用全屏程序。26.9.6 本组聚焦查找、日志诊断和结果整理，尚未提供 Vim 交互及 `tail -f` 持续跟踪，不把它们设为过关要求。`more` 的内容来自隔离环境中实际执行的工具，应用按每页 6 行展示并接管 Space/q 交互，不是完整 PTY 终端。

宿主机 Home、密钥和仓库不挂载进练习环境。命令无网络、限时 4 秒，文件写入和输出受大小限制。重置可以恢复初始文件。检查点与模型文件都是占位文件，不可加载为真实模型；26.9.3 的大文件采用稀疏占位，因此 `ls` 的 `total` 可能为 0，这不等于文件逻辑大小。

## 判题与日志

涉及文件操作时，本地检查直接验证最终目录、文件内容、缺失项和保留项，结合命令证据判题。Agent 阅读题目、最近 80 条命令与输出、解释和本地检查结果，不拥有工具执行权限。真实 API 调用失败或返回无效结果时不会标记通过。

每次提交在 `attempts/` 保存独立日志，包含全部本题命令历史（分页仅含已展示内容）、答案、题目快照、本地检查和评审状态。下次运行 `note` 会一起上传。没有提交的会话不保存。详见 [答题记录说明](./attempts/README.md)。

## 测试与扩展

```bash
python3 -m unittest discover -s practice-lab -v
# 需要图形桌面；不调用真实 API，不修改学生进度或日志
python3 practice-lab/ui_smoke.py
```

- `lessons.json`：章节、题目、评分要求、环境类型与最终状态检查。
- `core.py`：初始数据、隔离执行、分页、本地判题、API 与日志。
- `app.py`：桌面交互。
- `test_core.py` / `test_file_ops.py` / `test_text_ops.py`：原有题目回归、API 模拟、新题正向及失败路径。
- `ui_smoke.py`：26.9.4 / 26.9.6 共六道题的真实命令、分页按键、模拟评审、日志、完成标记与章节跳转。

题目尚不从新增笔记自动生成。新增题目应遵循仓库指导，配置必要数据并实际验证；不要把模拟评审测试描述为真实模型已验收。26.9.4 的测试记录见 [验证说明](./validation/26.9.4.md)。
