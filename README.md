# Learning Notes

个人机器学习与深度学习学习笔记，使用 Markdown 与 Typora 持续整理。

这里记录学习过程中的概念梳理、公式推导、直觉理解和阶段性疑问。内容以中文为主，按日期归档，主要用于复习与追踪自己的理解过程。

> 这是持续更新的个人学习记录，不是完整教程。部分内容可能尚未整理完毕，也可能随着后续学习继续修正。

## 主要内容

- 机器学习基础：Softmax 回归、损失函数、交叉验证、欠拟合与过拟合
- 训练与泛化：权重衰减、暂退法、参数初始化、分布偏移
- 神经网络组件：模型块、自定义层、参数共享、文件读写与 GPU
- 卷积神经网络：卷积、填充、步幅、池化、多通道与感受野
- 经典网络架构：LeNet、AlexNet、VGG、NiN、GoogLeNet
- 深层网络：Batch Normalization、ResNet、DenseNet
- 序列建模：循环神经网络、自回归、马尔可夫模型与文本预处理
