# Learning Notes

记录我学习深度学习及相关数学的过程：阅读论文、梳理原理，并用 PyTorch 代码核对理解。

笔记保留概念推导、对具体机制的追问、论文阅读，以及还没想通的问题和后来的修正。内容以中文为主，大多按日期归档，持续更新。

## 从这里开始

- **当前主线**：[机器翻译、编码器-解码器与注意力](./机器学习/26年9月/26.9.21.md)，从平行语料整理写到 seq2seq、束搜索、加性注意力、缩放点积注意力和多头注意力。
- **序列模型**：[RNN 学习笔记](./机器学习/26年9月/26.9.7.md)，梳理时间轴、网络深度、隐藏状态与参数之间的关系。后面的笔记继续写深度 RNN、双向 RNN 和现代循环网络。
- **论文阅读**：[阅读记录](./每日学术悦读/)，目前有 AlexNet、ResNet，以及单层 Transformer 的强化学习后训练。
- **代码实践**：[PyTorch 笔记](./PyTorch语法/)，从线性模型、数据加载写到卷积网络和循环网络。[MNIST 分类示例](./PyTorch语法/py/10.py) 包含数据加载、多层感知机、训练与测试。
- **数学基础**：[高等代数](<./数学/高等代数(丘维声)/>) 写到多项式的最大公因式、辗转相除和不可约分解；[离散数学（CS70）](<./数学/离散数学+概率论(cs70)/>) 整理证明、数学归纳法和稳定匹配。
