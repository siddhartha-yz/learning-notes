# 极简版路线图

```
人工智能
 ↓
机器学习
 ↓

 ↓
神经网络
 ↓

```

这节课主要建立一个认知框架：

> 深度学习不是魔法，而是一种让模型从数据中自动学习表示和映射的方法；PyTorch只是帮助我们快速搭建和训练这种模型的工具。

这份内容主要讲《PyTorch 深度学习实践》的“线性模型”入门。

核心流程：

1. 准备数据集。
2. 选择/设计模型。
3. 训练模型，确定参数。
4. 用训练好的模型对新数据做推理。

例子是：

$x=1,2,3,\qquad y=2,4,6$

选择最简单的线性模型：

$\hat y = wx$

训练的目标，就是找到最合适的 $w$。

为了判断某个 $w$ 好不好，引入损失函数。单个样本用平方误差：

$loss=(\hat y-y)^2$

整个训练集取平均：

$MSE=\frac{1}{N}\sum_{i=1}^{N}(\hat y_i-y_i)^2$

于是训练问题就变成：

> 找到一个 $w$，使 MSE 尽可能小。

在这个例子里，$w=2$ 时损失为 0，因此是最优解。

这节课暂时没有正式用梯度下降，而是用“穷举”理解训练：

```text
选一个 w
↓
计算所有样本预测值
↓
计算 MSE
↓
换一个 w
↓
寻找损失最低点
```

例如从 $0$ 到 $4$ 每隔 $0.1$ 测一个 $w$，画出：

$w \rightarrow Loss$

最终观察最低点。

另外强调了三个很重要的概念。

训练集：模型直接拿来学习的数据。

测试集：不能参与训练，只用来检查模型面对“没见过的数据”是否仍然有效。

开发集/验证集：从训练数据中额外划一部分，用于模型选择和观察训练效果。

这里引出了“泛化”和“过拟合”：

```text
训练集表现很好
≠
真实环境表现很好
```

如果模型连训练数据里的噪声都记住，就可能过拟合；我们真正希望的是模型对新数据也预测正确，即具有较好的泛化能力。

最后还有一个工程实践观点：训练深度模型时，要持续观察 loss 曲线、日志和验证集表现，并定期保存模型，因为真实训练可能持续数天甚至数周。

极简记忆：

$\boxed{ 数据 \rightarrow 模型 \rightarrow 预测 \rightarrow Loss \rightarrow 调参数 }$

这一讲最重要的思想不是“线性回归”，而是第一次完整建立了：

> **机器学习训练 = 定义模型 + 定义损失函数 + 寻找使损失最小的参数。**

这部分主要讲“梯度下降 → SGD → mini-batch SGD”的演进。

1. 为什么不用穷举搜索参数
   上一节是把 `w` 从一个范围内全部试一遍，找 MSE 最小值。但参数一多，搜索量会指数爆炸，比如 10 个参数、每个试 100 个值，就要搜索 $100^{10}$ 种组合，因此需要优化算法。
2. 梯度下降 Gradient Descent
   目标：找到让损失函数最小的参数。

核心思想：

$w \leftarrow w-\alpha\frac{\partial L}{\partial w}$

其中：

- $w$：参数
- $\frac{\partial L}{\partial w}$：梯度
- $\alpha$：学习率
- 负号：沿梯度反方向，让 loss 下降

每一步都朝当前下降最快的方向走。

1. 线性模型中的梯度
   模型：

$\hat y=wx$

平方损失：

$(\hat y-y)^2=(wx-y)^2$

对 $w$ 求导：

$\frac{\partial L}{\partial w} =2x(wx-y)$

如果对整个数据集求平均，就是：

$\frac{\partial MSE}{\partial w} = \frac{1}{N}\sum_{i=1}^{N}2x_i(wx_i-y_i)$

课程随后直接把这个解析式写进代码。

1. 训练循环

基本过程：

```python
for epoch in range(100):
    cost = compute_cost(...)
    grad = gradient(...)
    w = w - 0.01 * grad
```

即：

```text
计算 loss
→ 计算梯度
→ 更新 w
→ 重复
```

训练过程中 `loss` 通常逐渐降低，`w` 在示例中最终趋近于 `2`。

1. SGD：随机梯度下降
   普通梯度下降：

```text
用全部样本
→ 求平均梯度
→ 更新一次 w
```

SGD：

```text
取一个样本
→ 求这个样本的梯度
→ 立刻更新 w
→ 下一个样本
```

也就是把：

$\frac1N\sum_i \nabla L_i$

改成每次只用：

$\nabla L_i$

课程认为这种随机性可以帮助优化过程摆脱某些梯度很小或为零的位置。

1. 为什么实际主要用 mini-batch SGD
   两种极端：

```text
全量 Gradient Descent
优点：容易并行
缺点：每次要处理全部数据

SGD
优点：更新频繁、有随机性
缺点：一个样本一个样本更新，不利于并行
```

因此折中：

```text
mini-batch SGD
= 每次取一小批样本
→ 计算这一批的平均梯度
→ 更新一次参数
```

这也是现在深度学习最常见的训练方式。课程还特别说明，现在很多地方直接说 `batch`，实际通常指 `mini-batch`。

一句话总结：

```text
穷举参数
   ↓ 太慢
梯度下降：全部数据算一次梯度
   ↓
SGD：一个样本算一次梯度
   ↓
Mini-batch SGD：一小批样本算一次梯度
```

而现代深度学习实际最常用的是最后一种。



### pytorch是不是有个语法旧版本的写法是data，新版本是detach?

对，你说的是 PyTorch 中 **`.data` 和 `.detach()` 的变化**。

旧版本常见写法：

```python
x.data
```

新版本推荐：

```python
x.detach()
```

它们的目的类似：

> 获取一个和原 Tensor 共享数据，但是不参与梯度计算的新 Tensor。

------

例如：

```python
import torch

x = torch.tensor([1.0], requires_grad=True)

y = x * 2
```

此时：

```text
x → y
```

在计算图里。

如果：

```python
z = y.detach()
```

那么：

```text
x → y

z （脱离计算图）
```

修改 `z` 不会参与反向传播。

------

为什么不用 `.data`？

旧写法：

```python
z = y.data
```

问题：

`.data` 会直接绕过 autograd，可能导致计算图状态被悄悄破坏。

例如：

```python
y.data *= 2
```

PyTorch 不一定能发现你修改了需要梯度的信息，可能导致反向传播错误。

所以现在推荐：

```python
y.detach()
```

------

常见场景：

查看预测值：

旧：

```python
print(output.data)
```

新：

```python
print(output.detach())
```

转 numpy：

旧：

```python
output.data.numpy()
```

新：

```python
output.detach().numpy()
```

------

还有一个相关语法：

```python
with torch.no_grad():
    y = model(x)
```

表示整个代码块不记录梯度。

区别：

```text
detach()
→ 只切断某个 Tensor

no_grad()
→ 整个区域关闭梯度记录
```

所以现在 PyTorch 推荐：

- 不要用 `.data`
- 使用 `.detach()`
- 推理阶段使用 `torch.no_grad()` 或 `torch.inference_mode()`

### 不是说data过时了吗，我全部换成detach()直接报错了。

你这里报错的原因是：**`.detach()` 不是 `.data` 的直接替代品。**

你把：

```python
w.data = w.data - 0.01 * w.grad.data
```

替换成：

```python
w.detach() = w.detach() - 0.01 * w.grad.detach()
```

这是错误的。

原因：

```python
w.detach()
```

返回的是一个新的 Tensor：

```text
w.detach()
   ↓
一个脱离计算图的副本
```

它不是变量 `w` 本身，不能被赋值。

类似：

```python
5 = 3 + 2
```

左边不是变量，所以非法。

------

旧版本：

```python
w.data = w.data - 0.01 * w.grad.data
```

含义：

直接修改 `w` 内部存储的数据。

------

现在推荐写法：

```python
with torch.no_grad():
    w -= 0.01 * w.grad
```

完整替换：

```python
l.backward()

print("\tgrad:", x, y, w.grad.item())

with torch.no_grad():
    w -= 0.01 * w.grad

w.grad.zero_()
```

解释：

`torch.no_grad()`：

告诉 PyTorch：

> 这一步是更新参数，不需要建立新的计算图。

------

如果只是想替代：

```python
w.grad.data
```

可以：

```python
w.grad.detach()
```

例如：

```python
w -= 0.01 * w.grad.detach()
```

但是更新参数本身仍然建议放进：

```python
with torch.no_grad():
```

------

总结：

| 旧写法        | 新推荐                    |
| ------------- | ------------------------- |
| `w.data`      | `with torch.no_grad(): w` |
| `w.grad.data` | `w.grad.detach()`         |
| 查看Tensor    | `tensor.detach()`         |

所以不是 `.detach()` 被废弃，而是它用途不同。`.data` 是“绕过 autograd 修改数据”，`.detach()` 是“创建不参与梯度计算的 Tensor”。你这里属于前者。

# 反向传播

这节核心是 **PyTorch 如何实现反向传播（Back Propagation）**。

1. 神经网络本质是计算图

例如最简单线性模型：

$\hat y=xw$

计算过程：

```text
x, w
 ↓
乘法
 ↓
ŷ
 ↓
loss
```

PyTorch 中每次执行：

```python
l = loss(x, y)
```

都会动态构建一张计算图。

------

1. 为什么需要反向传播

简单模型可以手写梯度：

$\frac{\partial L}{\partial w}$

但是深度网络：

- 层数多
- 参数多
- 是复杂复合函数

手推所有导数不可行。

所以利用：

**链式法则 + 计算图**

自动传播梯度。

------

1. Forward（前向传播）

从输入开始：

```text
输入
 ↓
各层计算
 ↓
loss
```

计算：

- 输出值
- 中间结果
- 局部梯度



------

1. Backward（反向传播）

从 loss 开始：

```text
loss
 ↓
上一层
 ↓
上一层
 ↓
参数
```

利用链式法则：

$\frac{\partial L}{\partial x} = \frac{\partial L}{\partial z} \frac{\partial z}{\partial x}$

逐层计算梯度。

------

1. PyTorch 中 Tensor 的两个重要属性

Tensor：

```python
w = torch.Tensor([1.0])
```

默认：

```text
不计算梯度
```

需要训练：

```python
w.requires_grad = True
```

这样 PyTorch 才会记录计算图并计算：

$\frac{\partial loss}{\partial w}$



------

1. backward()

代码：

```python
l.backward()
```

作用：

沿计算图反向传播，把梯度保存到：

```python
w.grad
```



------

1. 参数更新

旧教程：

```python
w.data = w.data - 0.01*w.grad.data
```

原因：

更新参数只是数值操作，不应该重新建立计算图。

现代推荐：

```python
with torch.no_grad():
    w -= 0.01 * w.grad
```

------

1. 为什么每次 backward 后计算图释放？

流程：

```text
forward
 ↓
创建计算图
 ↓
loss.backward()
 ↓
得到梯度
 ↓
释放计算图
```

下一次训练：

重新 forward，重新创建图。

原因：

PyTorch 支持动态图，每次计算结构可以不同。

------

1. 为什么梯度要清零？

因为 PyTorch 默认梯度累加：

第一次：

$grad=g_1$

第二次：

$grad=g_1+g_2$

所以：

```python
w.grad.zero_()
```

清除旧梯度。

------

完整训练流程：

```python
for data in dataset:

    # forward
    loss = model(data)

    # backward
    loss.backward()

    # update
    with torch.no_grad():
        w -= lr * w.grad

    # clear gradient
    w.grad.zero_()
```

一句话总结：

> PyTorch 自动微分的核心就是：forward 动态建立计算图，backward 利用链式法则传播梯度，把梯度存入 `.grad`，然后用梯度下降更新参数。
