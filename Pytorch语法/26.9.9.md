## 1. 课程定位

这是一门**实践型 PyTorch 入门课**，目标不是深入数学推导，而是：

1. 学会实现深度神经网络。
2. 理解最基本的神经网络结构。

需要基础：

- 线性代数。
- 概率论与数理统计（理解随机变量、分布）。
- Python 编程（尤其 class、面向对象机制）。

------

## 2. 为什么课程不用最新版本 PyTorch？

核心观点：

**大学课程不会追逐最新工具，而强调长期有效的基础。**

原因：

- 发展期技术变化快，可能几年后淘汰。
- 应用期技术更加稳定，适合教学。
- 学习重点应该是：
  - 看懂原理。
  - 会查官方文档。
  - 能适应版本变化。

所以虽然课程使用 PyTorch 0.4，但核心思想仍然适用于新版。

# 3. 什么是智能？

课程给出的理解：

智能本质是：

> 根据输入的信息进行推理和预测。

例如：

“中午吃什么？”

输入：

- 钱多少。
- 个人偏好。
- 时间限制。

输出：

- 吃什么的决策。

这就是推理过程。

另一类：

看到图片 → 识别猫。

过程：

现实对象 → 抽象概念

这叫 prediction（预测）。


# 7. 为什么需要深度学习？

核心问题：

## 维度灾难

维度越高，需要的数据量指数增长。

例如：

1维：

```
10个点
```

2维：

```
10² = 100个点
```

10维：

```
10¹⁰ 个点
```

所以高维数据很难处理。

图片、文本、声音都是高维非结构数据。



------

# 8. ImageNet 与深度学习爆发

2012 年：

AlexNet 在 ImageNet 比赛中取得巨大突破：

错误率：

```
25.8%
 ↓
16.4%
```

随后：

ResNet 在 2015 年达到：

```
3.57%
```

超过人类约 5% 错误率。

这成为深度学习爆发的重要节点。

# 9. 神经网络来源

灵感来自神经科学。

1959 年猫视觉实验发现：

视觉处理具有层次结构：

低层：

- 边缘。
- 颜色。

高层：

- 猫。
- 狗。

对应：

```
简单特征
 ↓
复杂特征
 ↓
概念
```

这启发了现代神经网络。

------

# 10. 神经网络核心：反向传播

神经网络训练依靠：

**Back Propagation（反向传播）**

核心：

计算图 + 链式法则。

流程：

前向：

```
输入
 ↓
计算
 ↓
输出
```

反向：

```
Loss
 ↓
计算梯度
 ↓
更新参数
```

优势：

不用手写复杂求导，只需要定义基础算子。



------

# 11. 为什么使用 PyTorch？

PyTorch 特点：

- 动态计算图。
- Python 风格。
- 易调试。
- 自动梯度。
- 提供大量神经网络组件。

核心思想：

不要从零实现神经网络框架，而是：

> 学会组合基本模块构建模型。

类似编程：

```
基本语句
+
控制结构
=
复杂程序
```

深度学习：

```
卷积块
+
循环块
+
注意力块
=
复杂模型
```
