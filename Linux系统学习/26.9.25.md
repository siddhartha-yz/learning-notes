# systemctl控制软件启动关闭

极简总结：

`systemctl`：管理 Linux 的“服务”。

常用格式：

```bash
systemctl 操作 服务名
```

高频操作：

```bash
systemctl start 服务名      # 启动
systemctl stop 服务名       # 停止
systemctl status 服务名     # 查看状态
systemctl enable 服务名     # 开机自启
systemctl disable 服务名    # 关闭开机自启
```

例如：

```bash
systemctl status sshd
systemctl restart nginx
```

补充一个很常用但视频没重点讲的：

```bash
systemctl restart 服务名
```

= 重启服务。

核心理解：

```text
systemctl = Linux 服务管理器
服务 = 后台长期运行的软件
```

系统自带服务通常都能管理；第三方软件只有注册成 systemd 服务后才能被 `systemctl` 管理。
