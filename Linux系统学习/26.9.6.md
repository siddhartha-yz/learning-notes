# which-find-命令

极简总结：

`which`：查“命令本体在哪”。

```bash
which ls
```

会返回 `ls` 对应的可执行程序路径。

`find`：查文件。

按名字查：

```bash
find 起始路径 -name "文件名"
```

例如：

```bash
find / -name "*test*"
```

表示全盘查找名称中包含 `test` 的文件。

按大小查：

```bash
find 起始路径 -size +100M
```

- `+100M`：大于 100MB
- `-10k`：小于 10KB
- `+1G`：大于 1GB

核心：

```text
which = 找命令
find  = 找文件
```

# grep-wc-管道符

极简总结：

`grep`：按关键字过滤文本。

```bash
grep "关键字" 文件
grep -n "关键字" 文件   # 同时显示行号
```

`wc`：统计文本。

```bash
wc -l 文件   # 行数
wc -w 文件   # 单词数
wc -c 文件   # 字节数
wc -m 文件   # 字符数
```

管道符 `|`：把左边命令的输出，作为右边命令的输入。

```bash
cat test.txt | grep "test"
```

还可以连续使用：

```bash
cat test.txt | grep "test" | wc -l
```

一句话：

```text
grep = 筛选
wc   = 统计
|    = 把前一步结果交给下一步
```

# echo-tail-重定向符

极简总结：

`echo`：输出内容。

```bash
echo "hello linux"
```

反引号 ``命令``：先执行命令，再把结果放进去。

```bash
echo `pwd`
```

重定向：

```bash
命令 > 文件    # 覆盖写入
命令 >> 文件   # 追加写入
```

例如：

```bash
echo "hello" > test.txt
echo "world" >> test.txt
```

`tail`：查看文件末尾内容。

```bash
tail test.txt       # 默认最后10行
tail -5 test.txt    # 最后5行
tail -f test.txt    # 持续跟踪文件新增内容
```

核心：

```text
echo   = 输出
`...`  = 执行里面的命令
>      = 覆盖写
>>     = 追加写
tail   = 看文件尾部
```

# vim编辑器

极简总结：

`vi/vim`：Linux 命令行文本编辑器，`vim` 是增强版。

```bash
vim 文件
```

三种模式：

```text
命令模式  → 快捷键操作
输入模式  → 正常打字
底线模式  → 保存/退出
```

常用操作：

```text
i        进入输入模式
Esc      回命令模式
:w       保存
:q       退出
:wq      保存并退出
:q!      强制退出不保存
```

命令模式常用：

```text
dd       删除一行
yy       复制一行
p        粘贴
u        撤销
Ctrl+r   反撤销
gg       第一行
G        最后一行
/关键字   搜索
```

核心流程：

```text
vim 文件 → i 编辑 → Esc → :wq 保存退出
```
