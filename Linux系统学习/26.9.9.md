# Linux的root用户

极简总结：

### root 用户

- Linux 最大权限账户 = **root（超级管理员）**
- 普通用户权限受限：
  - 在自己的 `/home` 目录基本无限制
  - 离开 `/home` 后很多操作需要权限

------

### su：切换用户

语法：

```bash
su - 用户名
```

例：

```bash
su - root
su - ubuntu
```

说明：

- `-`：切换时加载目标用户环境变量（推荐加）
- 不写用户名：

```bash
su -
```

默认切换到 root。

权限区别：

```text
普通用户 → root
需要 root 密码

root → 普通用户
不需要密码
```

退出：

```bash
exit
```

或：

```text
Ctrl + D
```

------

### sudo：临时获取 root 权限

作用：

让普通用户**临时以 root 身份执行一条命令**。

语法：

```bash
sudo 命令
```

例：

```bash
sudo mkdir /test
```

特点：

- 不需要长期登录 root
- 比直接使用 root 更安全

------

### sudo 权限配置

配置文件：

```bash
/etc/sudoers
```

编辑：

```bash
visudo
```

添加用户权限：

```text
用户名 ALL=(ALL) NOPASSWD:ALL
```

表示：

- 该用户可以使用 sudo
- 不需要输入密码

------

核心区别：

| 命令   | 作用                       |
| ------ | -------------------------- |
| `su`   | 切换成另一个用户           |
| `sudo` | 当前用户临时执行 root 命令 |

实际开发中：

- 日常使用普通用户
- 需要管理员操作时使用 `sudo`
- 不建议长期使用 root 登录

# 用户和用户组

极简总结：

### 用户与用户组

Linux 支持：

- 多用户
- 多用户组
- 一个用户加入多个组

权限控制有两个层级：

1. 用户级别
2. 用户组级别

------

### 用户组管理

创建组：

```bash
groupadd 组名
```

例：

```bash
groupadd itcast
```

删除组：

```bash
groupdel 组名
```

------

### 用户管理

#### 创建用户

```bash
useradd 用户名
```

默认：

- 创建同名用户组
- home目录：

```text
/home/用户名
```

指定组：

```bash
useradd -g 组名 用户名
```

指定 home：

```bash
useradd -d 路径 用户名
```

------

#### 删除用户

```bash
userdel 用户名
```

只删除用户，不删除 home。

删除用户及 home：

```bash
userdel -r 用户名
```

------

### 查看用户信息

查看当前/指定用户：

```bash
id
```

或：

```bash
id 用户名
```

显示：

- 用户名
- UID
- 所属组

------

### 修改用户所属组

添加用户到组：

```bash
usermod -aG 组名 用户名
```

例：

```bash
usermod -aG itcast test4
```

表示：

- test4 加入 itcast 组
- 原来的组保留

------

### 查看系统用户

```bash
getent passwd
```

查看用户列表。

每行包含：

```
用户名:密码:UID:GID:描述:home目录:终端
```

------

### 查看系统用户组

```bash
getent group
```

显示：

```
组名:密码:GID
```

------

核心命令：

| 功能         | 命令            |
| ------------ | --------------- |
| 创建组       | `groupadd`      |
| 删除组       | `groupdel`      |
| 创建用户     | `useradd`       |
| 删除用户     | `userdel -r`    |
| 查看用户     | `id`            |
| 修改用户组   | `usermod -aG`   |
| 查看所有用户 | `getent passwd` |
| 查看所有组   | `getent group`  |

重点理解：

> Linux 权限管理的基础单位 = 用户 + 用户组。

# 查看权限控制信息

极简总结：

### ls -l 权限信息

查看：

```bash
ls -l
```

结果包含：

```
权限   所属用户   所属用户组
```

例如：

```
drwxr-xr-x  user  group  文件名
```

------

### 权限十个槽位

格式：

```
[类型][用户权限][用户组权限][其他用户权限]
```

共 10 位：

```
d rwx r-x r-x
│ │   │   │
│ │   │   └─ 其他用户
│ │   └──── 用户组
│ └──────── 文件所属用户
└────────── 文件类型
```

------

### 第一位：文件类型

| 符号 | 含义     |
| ---- | -------- |
| `-`  | 普通文件 |
| `d`  | 目录     |
| `l`  | 软链接   |

------

### 三种权限

| 权限 | 英文    | 文件         | 目录               |
| ---- | ------- | ------------ | ------------------ |
| r    | read    | 查看文件内容 | 查看目录内容       |
| w    | write   | 修改文件     | 创建/删除/改名文件 |
| x    | execute | 执行程序     | 进入目录(cd)       |

------

### 权限判断规则

Linux 判断权限顺序：

1. 如果自己是文件所属用户 → 看前三位
2. 如果属于文件所属组 → 看中间三位
3. 否则 → 看后三位

例：

```
-rw-r----- root root test.txt
```

当前用户：

- root → 看 `rw-`
- root组用户 → 看 `r--`
- 其他用户 → 看 `---`

------

### 文件 vs 目录重点区别

文件：

```
r = 看内容
w = 改内容
x = 执行
```

目录：

```
r = 查看里面有什么
w = 增删改文件
x = 能否进入(cd)
```

------

核心理解：

> Linux 权限 = 文件类型 + 用户权限 + 用户组权限 + 其他用户权限。
> `rwx` 在文件和目录上的含义不同，尤其目录的 `x` 代表进入权限。

# chmod命令

极简总结：

### chmod：修改权限

作用：

```bash
chmod 修改文件/目录权限
```

只有：

- 文件所属用户
- root用户

可以修改权限。

------

### 基础语法

```bash
chmod [-R] 权限 文件
```

`-R`：

- 递归修改目录及内部全部内容

例：

```bash
chmod -R 777 test
```

------

### 字母方式修改

格式：

```bash
chmod 用户对象=权限 文件
```

用户对象：

| 符号 | 含义            |
| ---- | --------------- |
| u    | 所属用户(user)  |
| g    | 所属组(group)   |
| o    | 其他用户(other) |

例：

```bash
chmod u=rwx,g=r,o=w test.txt
```

结果：

```text
用户：rwx
组：r--
其他：-w-
```

------

### 数字方式修改（常用）

权限数字：

| 权限 | 数字 |
| ---- | ---- |
| r    | 4    |
| w    | 2    |
| x    | 1    |

三位数字：

```text
用户  用户组  其他用户
 ↓      ↓       ↓
 7      5       1
```

计算：

| 数字 | 权限 |
| ---- | ---- |
| 0    | ---  |
| 1    | --x  |
| 2    | -w-  |
| 3    | -wx  |
| 4    | r--  |
| 5    | r-x  |
| 6    | rw-  |
| 7    | rwx  |

------

### 示例

```bash
chmod 751 test
```

等价：

```text
用户：rwx
组：r-x
其他：--x
```

因为：

```text
7 = 4+2+1 = rwx
5 = 4+1   = r-x
1 = 1     = --x
```

------

### 常用场景

给脚本执行权限：

```bash
chmod +x script.sh
```

或者：

```bash
chmod 755 script.sh
```

------

核心理解：

> chmod = change mode，修改权限。
> 权限数字计算规则：
> **r=4，w=2，x=1，三位数字分别代表用户/组/其他用户权限。**

# chown命令

极简总结：

## chown：修改所属用户/用户组

作用：

```bash
chown 修改文件或目录的所属用户、所属组
```

对应 `ls -l` 中：

```text
权限   所属用户   所属组
 ↓        ↓        ↓
rwx...  user     group
```

------

### 基础语法

```bash
chown [-R] 用户:用户组 文件
```

`-R`：

- 递归修改目录及内部全部内容

------

### 修改用户

```bash
chown root test.txt
```

表示：

```text
test.txt 所属用户 → root
```

不修改用户组。

------

### 修改用户组

```bash
chown :root test.txt
```

表示：

```text
test.txt 所属组 → root
```

冒号前为空，只修改组。

------

### 同时修改用户和组

```bash
chown root:root test.txt
```

表示：

```text
所属用户 → root
所属组 → root
```

------

### 修改目录及内部

```bash
chown -R root:root test
```

表示：

```text
test目录
└── 所有文件
    └── 所有子目录

全部改为 root:root
```

------

### 权限限制

`chown`：

- 普通用户不能使用
- 只有 root 可以执行

原因：

普通用户不能随意把文件转交给其他用户。

------

核心理解：

> `chmod` 改权限（rwx）
> `chown` 改归属（用户/用户组）

Linux文件控制三要素：

```text
权限：chmod
用户：chown
组：chown
```

常见组合：

```bash
chmod 755 file
chown root:root file
```

分别负责：

- 谁能访问
- 文件属于谁
- 文件属于哪个组

# 各类小技巧快捷键

极简总结：

# Linux 常用快捷键

## 1. Ctrl + C：强制停止

作用：

- 停止正在运行的命令
- 取消当前输入

例如：

```bash
tail -f test.txt
```

卡住时：

```text
Ctrl + C
```

退出。

------

## 2. Ctrl + D：退出

作用：

- 退出当前用户登录
- 退出部分交互程序

例如：

退出用户：

```bash
su - root
Ctrl + D
```

退出 Python：

```bash
python
Ctrl + D
```

------

# 历史命令

## 3. history：查看历史命令

```bash
history
```

查看以前执行过的命令。

------

## 4. !关键词：快速执行历史命令

格式：

```bash
!关键词
```

从历史记录中向前搜索第一个匹配命令。

例如：

```bash
!py
```

执行最近一次 python 命令。

适合近期命令。

------

## 5. Ctrl + R：搜索历史命令

```text
Ctrl + R
```

输入关键词搜索历史。

例如：

```text
Ctrl + R
pass
```

搜索包含 pass 的历史命令。

特点：

- 可搜索很久以前的命令
- 找到后：
  - Enter：直接执行
  - 左右键：取出修改

------

# 光标移动

## 6. Ctrl + A

移动到命令开头：

```text
Ctrl + A
```

------

## 7. Ctrl + E

移动到命令结尾：

```text
Ctrl + E
```

------

## 8. Ctrl + ← / →

按单词移动：

```text
Ctrl + ←
Ctrl + →
```

快速跳过单词。

------

# 清屏

## 9. Ctrl + L

清空终端显示：

```text
Ctrl + L
```

等价于：

```bash
clear
```

注意：

- 只是清屏
- 不删除历史命令

------

核心记忆：

| 快捷键   | 作用              |
| -------- | ----------------- |
| Ctrl+C   | 停止命令/取消输入 |
| Ctrl+D   | 退出              |
| history  | 查看历史          |
| !关键词  | 执行最近匹配命令  |
| Ctrl+R   | 搜索历史命令      |
| Ctrl+A   | 到开头            |
| Ctrl+E   | 到结尾            |
| Ctrl+←/→ | 按单词移动        |
| Ctrl+L   | 清屏              |

这些快捷键是 Linux 终端日常高频操作。
