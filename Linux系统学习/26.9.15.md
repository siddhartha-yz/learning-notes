### 1. Linux 安装软件的两种方式

- 手动下载安装包安装
- 使用系统自带的软件包管理器联网安装

软件包管理器类似 Windows 的“应用商店”，还能自动处理依赖。

### 2. CentOS：`yum`

CentOS 常见软件包格式：`.rpm`

基本语法：

```bash
yum install 软件名     # 安装
yum remove 软件名      # 卸载
yum search 软件名      # 搜索
```

例如：

```bash
sudo yum install wget
```

加 `-y` 可以自动确认：

```bash
sudo yum install -y wget
```

否则安装过程中通常需要手动输入 `y` 确认。

### 3. Ubuntu：`apt`

Ubuntu 常见软件包格式：`.deb`

`apt` 的作用与 `yum` 基本相同：

```bash
sudo apt install 软件名
sudo apt remove 软件名
apt search 软件名
```

例如：

```bash
sudo apt install wget
```

自动确认：

```bash
sudo apt install -y wget
```

### 4. 你目前最需要记住

你用 Ubuntu，所以主要记：

```bash
sudo apt install 软件名
sudo apt remove 软件名
apt search 软件名
```

一句话理解：

> `apt` 就是 Ubuntu 命令行里的“软件商店”，负责搜索、下载、解决依赖并安装软件。
