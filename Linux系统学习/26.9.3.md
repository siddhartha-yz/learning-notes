# Linux目录结构

- Linux 没有 `C盘/D盘`，整个文件系统只有一个顶级目录：根目录 `/`
- 所有文件、文件夹都属于这棵以 `/` 为根的目录树
- Linux 路径用 `/` 分隔层级，例如：

```bash
/usr/local/hello.txt
```

含义：

```text
/        根目录
usr      根目录下的 usr
local    usr 下的 local
hello.txt local 下的文件
```

关键点：路径开头的 `/` 表示根目录；中间的 `/` 表示目录层级关系。

一句话：Linux 整个文件系统就是“一棵从 `/` 开始的树”。

# Linux命令基础

极简总结：

Linux 主要通过终端（Terminal）输入命令操作系统。

命令通用格式：

```bash
command [options] [parameter]
```

- `command`：命令本身，必须有
- `options`：选项，控制命令怎么做
- `parameter`：参数，控制命令对谁做

例如：

```bash
ls -l /home
```

其中：

```text
ls      命令
-l      选项
/home   参数
```

一句话：Linux 命令 ≈ “做什么 + 怎么做 + 对谁做”。

# ls命令入门

极简总结：

`ls`：列出目录中的内容。

```bash
ls
```

不带参数时，显示当前工作目录里的文件和文件夹。

两个概念：

- 当前工作目录：你此刻“所在”的目录。
- Home 目录：当前用户自己的主目录，通常是：

```text
/home/用户名
```

终端打开时，一般默认就在 Home 目录。

一句话：`ls` = “看看我当前这个目录里有什么”。

# ls命令的参数和选项

极简总结：

`ls` 可以指定目录：

```bash
ls /etc
```

表示查看 `/etc` 里的内容。

常用选项：

```bash
ls -a   # 显示隐藏文件
ls -l   # 详细列表
ls -lh  # 详细列表 + 人类易读的文件大小
```

Linux 中以 `.` 开头的文件默认是隐藏文件。

选项可以组合：

```bash
ls -lah /home
```

一句话：`ls` = “看哪里”，选项 = “怎么看”。

# cd-pwd命令

极简总结：

`cd`：切换当前工作目录（change directory）

```bash
cd /路径
```

例如：

```bash
cd /
```

进入根目录。

```bash
cd
```

不带参数，返回当前用户的 Home 目录。

`pwd`：查看当前工作目录（print work directory）

```bash
pwd
```

输出当前所在路径。

核心关系：

```text
cd     改变“我在哪”
pwd    查看“我在哪”
ls     查看“这里有什么”
```

一句话：`cd`负责移动，`pwd`负责定位，`ls`负责查看。
