# 相对路径，绝对路径和特殊路径符

极简总结：

Linux 路径分三类：

### 1. 绝对路径

从根目录 `/` 开始写：

```bash
cd /home/user/Desktop
```

特点：开头一定是 `/`。

------

### 2. 相对路径

从当前工作目录开始写：

```bash
cd Desktop
```

等价：

```bash
cd ./Desktop
```

特点：开头不是 `/`。

------

### 3. 特殊路径符

```text
.       当前目录
..      上一级目录
~       当前用户 Home 目录
```

例：

```bash
cd ..
```

返回上一级。

```bash
cd ~
```

回到 Home。

```bash
cd ~/Desktop
```

进入 Home 下的 Desktop。

------

核心记忆：

```
/  = 从系统根开始找
./ = 从当前位置找
../ = 往上一层找
~  = 回家(Home)
```

一句话：绝对路径找“全地址”，相对路径找“附近位置”。

# mkdir命令

极简总结：

`mkdir`：创建目录（make directory）

```bash
mkdir 目录名
```

例如：

```bash
mkdir test
```

支持相对路径、绝对路径、`~`、`..` 等。

创建多级目录：

```bash
mkdir -p a/b/c
```

`-p`：父目录不存在时一起创建。

一句话：

```text
mkdir      创建目录
mkdir -p   连父目录一起创建
```

# touch-cat-more-命令

极简总结：

```bash
touch 文件名
```

创建文件，例如：

```bash
touch test.txt
```

查看文件内容：

```bash
cat test.txt
```

一次性全部输出。

```bash
more test.txt
```

分页查看，适合长文件：

```text
Space  下一页
q      退出
```

补充：`ls -l` 中，开头 `d` 表示目录，`-` 表示普通文件。

# cp-mv-rm-命令

极简总结：

```bash
cp 源 目标
```

复制文件；复制目录要加 `-r`：

```bash
cp -r dir1 dir2
mv 源 目标
```

移动文件/目录；若目标不存在，也可用于重命名。

```bash
rm 文件
rm -r 目录
```

删除文件/目录。

常用通配符：

```text
test*    以 test 开头
*test    以 test 结尾
*test*   包含 test
```

`rm -f`：强制删除、不确认。

核心：

```text
cp = 复制
mv = 移动/改名
rm = 删除
```

`rm` 很危险，尤其是 `rm -rf`，不要随便对 `/` 使用。
