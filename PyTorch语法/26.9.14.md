# 加载数据集

PyTorch 中如何用 `Dataset + DataLoader` 实现 Mini-Batch 训练。

1. `Dataset` 和 `DataLoader`

- `Dataset`：负责管理数据集。
  - 支持按索引取样本：`dataset[i]`
  - 支持获取数据集大小：`len(dataset)`
- `DataLoader`：负责从 `Dataset` 中批量取数据。
  - 分 batch
  - shuffle
  - 多进程加载数据

自定义 `Dataset` 一般需要实现：

```python
class MyDataset(Dataset):
    def __init__(self):
        ...

    def __getitem__(self, index):
        return x, y

    def __len__(self):
        return self.len
```

也就是核心两个魔法方法：

```python
__getitem__()
__len__()
```



1. 为什么使用 Mini-Batch

三种梯度下降方式：

```text
Batch GD
一次使用全部数据
→ 计算并行效率高，但随机性弱

SGD
一次使用 1 个样本
→ 随机性强，但 GPU/CPU 利用率低

Mini-Batch GD
一次使用一小批数据
→ 在计算效率和随机性之间折中
```

深度学习实际训练通常使用 Mini-Batch。

1. 三个重要概念

假设：

```text
数据集：10000 个样本
batch_size = 1000
```

那么：

```text
batch_size = 1000
iteration = 10
epoch = 所有 10000 个样本完整训练一次
```

关系可以简单理解为：

```text
1 epoch
    ↓
很多 iteration
    ↓
每个 iteration 处理 1 个 mini-batch
```

因此大致有：

```text
iteration ≈ 数据集大小 / batch_size
```



1. `DataLoader` 常见参数

```python
train_loader = DataLoader(
    dataset=dataset,
    batch_size=32,
    shuffle=True,
    num_workers=2
)
```

含义：

```text
dataset       数据集
batch_size    每批样本数
shuffle       是否打乱数据
num_workers   用几个进程加载数据
```

训练集通常：

```python
shuffle=True
```

这样不同 epoch 中样本组合会变化。

1. 大数据集不要全部塞进内存

小型表格数据可以：

```python
__init__()
    ↓
直接全部加载到内存
```

但图像、语音等大型数据集可能几十 GB，此时更合理的是：

```text
__init__
→ 只保存文件路径、标签等索引信息

__getitem__
→ 真正需要第 i 个样本时，再读取文件
```

这也是 `Dataset` 设计非常重要的思想：懒加载。

1. 使用 `DataLoader` 后的训练循环

原来：

```python
for epoch in range(100):
    # 全部数据训练一次
```

现在变成双重循环：

```python
for epoch in range(100):
    for x, y in train_loader:
        y_pred = model(x)

        loss = criterion(y_pred, y)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

结构：

```text
epoch 循环
    ↓
batch 循环
    ↓
forward
    ↓
loss
    ↓
zero_grad
    ↓
backward
    ↓
optimizer.step()
```



1. 标准 PyTorch 训练程序四步

这一讲再次强调了整个 PyTorch 训练框架：

```text
① 准备数据 Dataset + DataLoader
② 定义 Model
③ 定义 Loss + Optimizer
④ Training Cycle
```

这一讲相比前面主要修改的是：

```text
① 数据准备
④ 训练循环
```

因为从 Full Batch 改成了 Mini-Batch。

1. `torchvision.datasets`

PyTorch 已经提供了很多标准数据集，例如 MNIST。

典型：

```python
train_set = datasets.MNIST(
    root="./dataset",
    train=True,
    transform=transforms.ToTensor(),
    download=True
)
```

然后：

```python
train_loader = DataLoader(
    train_set,
    batch_size=32,
    shuffle=True
)
```

训练集通常 `shuffle=True`，测试集一般 `shuffle=False`。

整讲最需要记住的其实只有这一张图：

```text
Dataset
负责「一个样本怎么取」
        ↓
DataLoader
负责「怎么组成一个 batch」
        ↓
for x, y in train_loader
        ↓
Model
        ↓
Loss
        ↓
Backward
        ↓
Optimizer
```

一句话总结：

> `Dataset` 定义“数据是什么、怎么拿一个”，`DataLoader` 定义“训练时怎么一批一批地拿”。
