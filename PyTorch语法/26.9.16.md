# 多分类问题

这节《PyTorch 深度学习实践》第 9 讲，核心是：用 Softmax + 交叉熵解决多分类问题。

1. 多分类为什么需要 Softmax

二分类只需要输出一个概率 $P(y=1)$，另一个就是 $1-P(y=1)$。

但 MNIST 有 10 类，如果给 10 个类别分别独立做二分类，可能出现：

$P(y=1)=0.8,\quad P(y=2)=0.8,\quad P(y=3)=0.9$

这不符合“一个样本只能属于一个类别”的概率分布要求。

因此希望输出满足：

$p_i>0,\qquad \sum_i p_i=1$

也就是说，各类别之间具有竞争关系：某一类概率变大，其他类别概率就会相应受到压制。

1. Softmax

设网络最后线性层输出：

$z_1,z_2,\dots,z_K$

Softmax：

$p_i=\frac{e^{z_i}}{\sum_{j=1}^{K}e^{z_j}}$

其中：

- $e^{z_i}>0$：保证概率为正；
- 除以所有指数之和：保证所有概率之和为 1。

例如：

$[0.2,0.1,-0.1]$

经过 Softmax 后大约变成：

$[0.38,0.34,0.28]$

成为真正的概率分布。

1. 交叉熵损失

如果真实类别是第 $k$ 类，交叉熵实际上只关心模型给真实类别的概率：

$L=-\log p_k$

预测真实类别的概率越高，损失越小。

PyTorch 中通常直接：

```python
criterion = torch.nn.CrossEntropyLoss()
```

`CrossEntropyLoss` 已经包含：

```text
Softmax → Log → NLLLoss
```

所以模型最后一层不要自己加 Softmax，直接输出原始线性结果 logits：

```python
output = self.linear(x)
loss = criterion(output, label)
```

标签则直接写类别编号 `0~9`，并使用 `LongTensor`，不需要手动转成 one-hot。

1. MNIST 数据预处理

MNIST：

$28\times28=784$

每张图为单通道灰度图。

使用：

```python
transforms.ToTensor()
```

完成：

```text
0~255 → 0~1
28×28 → 1×28×28
```

再使用：

```python
transforms.Normalize((0.1307,), (0.3081,))
```

根据 MNIST 的均值和标准差进行标准化。

1. 全连接网络结构

输入 batch：

$N\times1\times28\times28$

首先展平：

```python
x = x.view(-1, 784)
```

变成：

$N\times784$

然后：

```text
784
 ↓
512 → ReLU
 ↓
256 → ReLU
 ↓
128 → ReLU
 ↓
64  → ReLU
 ↓
10
```

最后的 `10` 对应数字 `0~9` 的 10 个类别，并且最后一层不加激活函数。

1. 训练流程

基本流程仍然是：

```python
optimizer.zero_grad()

outputs = model(inputs)
loss = criterion(outputs, labels)

loss.backward()
optimizer.step()
```

即：

```text
梯度清零
→ 前向传播
→ 计算损失
→ 反向传播
→ 更新参数
```

累计损失时使用：

```python
loss.item()
```

避免把整个计算图一起保存。

1. 测试流程

测试时不需要梯度：

```python
with torch.no_grad():
```

模型输出：

$N\times10$

对每个样本找到最大的那个输出：

```python
_, predicted = torch.max(outputs.data, dim=1)
```

其下标就是预测类别。

最后：

$Accuracy= \frac{\text{预测正确数量}} {\text{总样本数量}}$



这节课可以压缩成一条主线：

```text
MNIST 图片
→ ToTensor / Normalize
→ Flatten 成 784 维
→ 多层全连接 + ReLU
→ 输出 10 个 logits
→ CrossEntropyLoss
→ 自动完成 Softmax + 交叉熵
→ argmax 得到预测类别
```

最需要记住的是：

```text
多分类：
最后一层输出类别数个 logits
        ↓
不要手动 Softmax
        ↓
CrossEntropyLoss
        ↓
标签直接用类别编号 LongTensor
```

这个全连接网络在 MNIST 上大约可以达到 97% 准确率，但由于把图像完全展平，忽略了图像局部空间结构，因此后续更适合使用 CNN 自动提取图像特征。

# 卷积神经网络（基础篇）

为啥卷积层要增加通道数。



因为卷积层不仅要“缩小图片”，还要提取越来越多种特征。

你可以把“通道数”理解成：

> 通道数 = 网络同时记录的“特征种类数”。

比如你图里：

$1\times28\times28 \rightarrow 4\times24\times24 \rightarrow 4\times12\times12 \rightarrow 8\times8\times8$

第一层从 1 个通道变成 4 个通道，本质上是用了 4 组不同的卷积核：

- 第 1 个可能学竖边
- 第 2 个可能学横边
- 第 3 个可能学斜边
- 第 4 个可能学某种纹理

所以产生 4 张 feature map。

到了更深层，网络需要描述的特征更复杂，比如从“边缘”逐渐组合成“笔画”“局部形状”等，于是通常增加通道数：

$4\text{种特征}\rightarrow8\text{种特征}$

还有一个重要原因：空间尺寸通常在下降。

例如：

$4\times12\times12=576$

经过后面的缩小，如果通道还是 4：

$4\times8\times8=256$

信息表示能力会下降很多。因此常见设计是：

> $H,W$ 越来越小，$C$ 越来越大。

也就是：

$\boxed{\text{空间分辨率降低，特征种类增加}}$

但注意：**卷积层并不是必须增加通道数。** `C_out` 是人为设计的超参数。只不过深层网络里“尺寸减半、通道增加”是非常常见的设计。

你可以暂时记成一句话：

> **一张特征图负责描述一种特征；网络越深，需要描述的特征种类通常越多，所以通道数往往增加。**



可我感觉这4组不同的卷积核是对称的啊，怎么能够保证他学习了4中不同的特征？



对，结构上它们确实是完全对称的。关键在于：训练开始时会用随机初始化把这种对称性打破。

比如 4 个卷积核结构都是 $5\times5$，但初始参数不同：

$W_1\neq W_2\neq W_3\neq W_4$

虽然它们都看同一张图片，但因为初始权重不同，第一次前向传播得到的特征图就不同，随后反向传播得到的梯度也不同：

$\frac{\partial L}{\partial W_1} \neq \frac{\partial L}{\partial W_2} \neq \frac{\partial L}{\partial W_3} \neq \frac{\partial L}{\partial W_4}$

于是它们越训练越可能“分工”，最终对不同模式敏感。

反过来，如果你强行让 4 个卷积核：

$W_1=W_2=W_3=W_4$

而且完全相同地初始化，那么它们通常会收到相同梯度、一起更新，最后仍然一模一样——等于白白复制了 4 份。

这就是神经网络里经典的“对称性破缺”问题。

所以最准确的说法是：

> 网络并没有显式保证“第一个学横线、第二个学竖线”；它只是用随机初始化打破对称性，然后训练过程中让不同卷积核自然学到不同的特征。

至于最后是不是严格“四种不同特征”，也不保证。有时两个卷积核会学得比较相似，这也是正常的。
