# 处理多维特征的输入

这节主要讲：如何把前面的单变量逻辑回归，扩展到“多维输入 + 多层神经网络”。

1. 多维输入
   一个样本不再只有一个 $x$，而是多个特征：

$x=(x_1,x_2,\dots,x_8)$

线性部分变成：

$z=x^Tw+b$

再经过 Sigmoid：

$\hat y=\sigma(z)$

用于二分类。

1. Batch 本质是矩阵计算
   多个样本放在一起：

$X\in \mathbb R^{n\times 8},\quad W\in\mathbb R^{8\times1}$

于是：

$Z=XW+b$

把逐样本计算转成矩阵运算，可以利用 CPU/GPU 并行，比 Python `for` 循环高效。

1. `nn.Linear(a,b)` 的直觉
   可以理解为：

> 把 $a$ 维空间线性映射到 $b$ 维空间。

例如：

```python
nn.Linear(8, 6)
nn.Linear(6, 4)
nn.Linear(4, 1)
```

就是：

$8\rightarrow6\rightarrow4\rightarrow1$

维度也不一定一直下降，可以先升维再降维。

1. 为什么需要激活函数
   如果只是不断堆 `Linear`，仍然只是线性变换。

因此每层之间加入 Sigmoid 等激活函数：

$x\rightarrow Linear\rightarrow\sigma \rightarrow Linear\rightarrow\sigma$

通过非线性激活，让神经网络能够拟合复杂的非线性空间变换。

1. 网络越大不一定越好
   层数、隐藏神经元数量都是超参数。

模型过复杂可能把训练数据中的噪声也学进去，导致泛化能力下降，因此需要通过实验进行超参数搜索。

1. 数据读取
   课程示例把 CSV 数据读入 NumPy：

```python
xy = np.loadtxt(..., delimiter=',', dtype=np.float32)
```

再拆分：

```python
x_data = ...
y_data = ...
```

然后：

```python
torch.from_numpy(...)
```

转成 Tensor。课程特别强调保证 $X$、$Y$ 的矩阵维度正确。

1. PyTorch 网络结构
   核心形式：

```python
self.linear1 = nn.Linear(8, 6)
self.linear2 = nn.Linear(6, 4)
self.linear3 = nn.Linear(4, 1)
self.sigmoid = nn.Sigmoid()
```

`forward()` 中连续复用 `x`：

```python
x = self.sigmoid(self.linear1(x))
x = self.sigmoid(self.linear2(x))
x = self.sigmoid(self.linear3(x))
return x
```

这样比 `o1/o2/o3` 更不容易接错层。

1. 损失函数和优化器
   因为仍然是二分类概率输出，所以损失函数和前面的逻辑回归基本不变，继续使用 BCE；优化器仍然优化 `model.parameters()`。这一讲暂时把全部数据一起训练，真正的 mini-batch 后面通过 `DataLoader` 实现。

一句话概括：

> 多维输入本质是把标量运算变成矩阵运算；多层神经网络本质是不断进行“线性空间变换 + 非线性激活”，从而学习复杂的非线性映射。
