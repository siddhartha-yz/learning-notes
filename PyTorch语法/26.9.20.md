# 循环神经网络（基础篇）

这一讲主要讲 RNN（循环神经网络）基础，以及 One-hot、Embedding、LSTM、GRU。

RNN 主要处理有顺序关系的数据，例如天气、股市、文本、视频。普通全连接网络如果直接把长序列展开，会带来大量参数，而且没有很好利用“前后依赖”；RNN 则通过时间步之间共享权重来处理序列。

最核心的计算是：

$h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b)$

其中：

- $x_t$：当前时刻输入
- $h_{t-1}$：上一时刻隐藏状态
- $h_t$：新的隐藏状态

直觉上：

```text
x1 + h0 → h1
x2 + h1 → h2
x3 + h2 → h3
...
```

关键在于：每个时间步用的是同一套权重。

所以图上虽然画了很多 RNN Cell：

```text
x1 → [RNN] → h1
       ↓
x2 → [RNN] → h2
       ↓
x3 → [RNN] → h3
```

实际上这些 `[RNN]` 是同一个模块被反复调用，不是三套不同参数。

PyTorch 有两种主要写法。

`RNNCell`：一次只处理一个时间步，因此需要自己写循环：

```python
for x_t in sequence:
    h = cell(x_t, h)
```

其维度通常是：

$x_t:(batch,input\_size)$

$h_t:(batch,hidden\_size)$



`RNN`：一次直接输入整个序列，不需要自己写时间循环。

默认输入：

$(seq\_len,batch,input\_size)$

输出：

$output:(seq\_len,batch,hidden\_size)$

如果有多层 RNN：

$h_n:(num\_layers,batch,hidden\_size)$

其中 `output` 保存最后一层 RNN 在每个时间步的输出，而 $h_n$ 保存各层最终时刻的隐藏状态。设置 `batch_first=True` 后，输入可以改成：

$(batch,seq\_len,input\_size)$



这一讲还做了一个简单的 Seq2Seq 字符任务，例如：

```text
hello → ohlol
```

首先文本不能直接送进神经网络，因此需要把字符数字化。

最简单方法是 One-hot。例如词表：

```text
e → 0
h → 1
l → 2
o → 3
```

那么：

$h\rightarrow[0,1,0,0]$

$l\rightarrow[0,0,1,0]$

RNN 每个时间步输出一个向量，再把它看成对不同字符类别的预测，用交叉熵训练。

训练 `RNNCell` 时，一个重要细节是每个时间步的 loss 要保留在计算图中，再整体反向传播：

```text
loss1
+ loss2
+ loss3
+ ...
→ backward()
```

不能提前 `.item()`，因为 `.item()` 会把 Tensor 变成普通数值，从计算图中脱离。

One-hot 有三个明显问题：

- 维度很高；
- 非常稀疏；
- 表示是硬编码的。

因此引入 Embedding：

$\boxed{\text{离散 ID}\rightarrow\text{可学习的稠密向量}}$

例如：

```text
word id = 2
↓
Embedding
↓
[0.13, -0.52, 0.87, ...]
```

Embedding 本质上可以理解为一个可训练的查表矩阵；反向传播会更新里面的向量。

因此更正常的 NLP 网络结构是：

```text
Token ID
↓
Embedding
↓
RNN
↓
Linear
↓
CrossEntropyLoss
```

其中 RNN 的 `hidden_size` 不需要等于类别数量，因为可以再加一个线性层：

$hidden\_size\rightarrow num\_classes$



最后介绍了 LSTM 和 GRU。

普通 RNN 在长序列上容易遇到梯度传播困难。LSTM 增加了一条 cell state：

$C_{t-1}\rightarrow C_t$

让信息和梯度有更直接的传播路径，从而缓解梯度消失。LSTM 因此除了 $h_t$，还有 $C_t$：

```text
(h0, c0)
    ↓
  LSTM
    ↓
(hn, cn)
```

课程强调，“遗忘门”“输入门”等名称主要是帮助建立直觉，实现时核心仍然是具体公式。

GRU 则可以理解成 RNN 与 LSTM 之间的折中：

```text
普通 RNN
    ↓
结构简单、计算快
但长距离依赖较弱

GRU
    ↓
更复杂
长依赖能力更强

LSTM
    ↓
结构更复杂
计算成本更高
```

这讲最值得记住的是：

$\boxed{h_t=f(x_t,h_{t-1})}$

以及：

$\boxed{\text{时间步不同，但共享同一套参数}}$

整个知识链可以压缩为：

```text
序列数据
↓
RNN：隐藏状态传递信息
↓
RNNCell：手动循环
RNN：内部自动循环
↓
One-hot 表示离散符号
↓
Embedding 学习稠密表示
↓
LSTM / GRU 改进长距离依赖
```

其中学习 PyTorch RNN 时最容易出问题、也最应该掌握的是：**张量 shape + 隐藏状态 $h_t$ + 时间步共享参数。**
