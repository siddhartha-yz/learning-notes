## 2. 命题 vs 非命题

**命题：** 非真即假的陈述。真假不取决于我们是否知道答案。

**课上例子**

| 语句                            | 是命题？     | 说明                                                    |
| ------------------------------- | ------------ | ------------------------------------------------------- |
| 三角形内角和 \(=180^\circ\)     | 定义清楚后是 | 欧氏 vs 非欧没说清时还不算                              |
| \(\forall n,\ n^2+n+41\) 为质数 | 是（且为假） | \(n=0,1,2,\ldots\) 很长时间都是质数，\(n\) 够大出现合数 |
| 哥德巴赫猜想                    | 是           | 1742 年至今不知真假，仍非真即假                         |
| 华盛顿是美国首都                | 是           |                                                         |
| 伯克利是有趣的城市              | **否**       | 「有趣」含糊，看法会分歧                                |

课上强调：生物学家/物理学家会在一串质数后停手，数学家要证明或反例；计算机科学家更像哪边，取决于语境——这正是后面要学证明的理由。

**讲义有、课上没用同一批例子：** \(\sqrt{3}\) 无理、\(1+1=5\)、凯撒早餐；非命题：`2+2`（不是陈述）、\(x^2+3x=5\)（\(x\) 未定）、often / unpopular 一类含糊词。

## 3. 联结词 \(\land\ \lor\ \lnot\)、永真式、矛盾、排中律

**课上讲了：** 与、或、非。合取仅当 \(P,Q\) 都真；析取至少一真即为真，仅当两者都假才假。提到 **modus ponens（肯定前件）**，没有展开证明系统。

**讲义有、课上略过名词：**

- **排中律：** 对任意 \(P\)，\(P\) 或 \(\lnot P\) 成立（不能同时）  
- **永真式：** 无论变元取值都真，如 \(P\lor\lnot P\)  
- **矛盾：** 永远为假，如 \(P\land\lnot P\)

---

## 4. 蕴涵 \(P\Rightarrow Q\)、空真、必要/充分

**含义：** 「若 \(P\) 则 \(Q\)」。只承诺一件事：前件真时后件必须真。

**真值表（课上填了）**

| \(P\) | \(Q\) | \(P\Rightarrow Q\) |
| ----- | ----- | ------------------ |
| T     | T     | T                  |
| T     | F     | F（承诺破产）      |
| F     | T     | T                  |
| F     | F     | T                  |

前件为假时，蕴涵不需要「负责」——逻辑上叫 **空真**。

**讲义有、课上没展开：**

- \((P\Rightarrow Q)\equiv(\lnot P\lor Q)\)  
- 同一蕴涵的说法：if \(P\) then \(Q\)；\(Q\) if \(P\)；\(P\) only if \(Q\)；\(P\) 是 \(Q\) 的**充分**条件；\(Q\) 是 \(P\) 的**必要**条件  
- 当且仅当：\(P\iff Q\)（双向蕴涵）

---

## 5. 逆否 vs 逆命题

|            | 形式                          | 与 \(P\Rightarrow Q\)      |
| ---------- | ----------------------------- | -------------------------- |
| **逆否**   | \(\lnot Q\Rightarrow\lnot P\) | **逻辑等价**（真值表相同） |
| **逆命题** | \(Q\Rightarrow P\)            | 一般**不等价**             |

课上完整做了逆否：证明里把蕴涵改写成逆否，往往比直接证 \(P\Rightarrow Q\) 容易。  
**逆命题**讲义单独警告「别和逆否搞混」，这一讲没对比。

（ASR 把「蕴涵 / 逆否」听成「运函 / 逆逢」，这里已按讲义校正。）

---

## 6. \(\forall\) \(\exists\)、量词不可交换

简单命题不够用时，对**论域**量化：

- **全称 \(\forall\)：** 论域里每一个都满足，如 \((\forall n\in\mathbb{N})(n^2+n+41\text{ 为质数})\)  
- **存在 \(\exists\)：** 至少有一个满足  

有穷论域上：\(\forall\) 是合取，\(\exists\) 是析取；无穷论域不能这样展开。

**讲义高潮、课上没时间：** 量词**不可交换**。

- 「每次乘地铁都有人被刺」vs「有同一个人每次都被刺」  
- \((\forall x\exists y)(x<y)\) 真（总能找到更大整数）  
- \((\exists y\forall x)(x<y)\) 假（不存在最大整数）

---

## 7. 否定与德摩根

**课上收尾（量化否定）：**

\[
\lnot\exists x\,P(x)\ \equiv\ \forall x\,\lnot P(x)
\]

否定号往里推，每过一个量词就**翻转**。多层同样：\(\lnot(\forall x\exists y\,P(x,y))\equiv\exists x\forall y\,\lnot P(x,y)\)。

**讲义有、课上没写联结词德摩根：**

\[
\lnot(P\land Q)\equiv(\lnot P\lor\lnot Q),\qquad
\lnot(P\lor Q)\equiv(\lnot P\land\lnot Q)
\]

以及对称的 \(\lnot\forall x\,P(x)\equiv\exists x\,\lnot P(x)\)。

__无穷论域不能展开合取和析取吗？__

对。在普通一阶逻辑里，只有有限论域才能严格地把量词展开成有限的合取/析取。

例如论域

$D=\{a,b,c\}$

那么

$\forall x\,P(x)$

等价于

$P(a)\land P(b)\land P(c)$

而

$\exists x\,P(x)$

等价于

$P(a)\lor P(b)\lor P(c)$

但如果论域是无限的，比如

$D=\{a_1,a_2,a_3,\dots\}$

那就需要写成

$P(a_1)\land P(a_2)\land P(a_3)\land\cdots$

或者

$P(a_1)\lor P(a_2)\lor P(a_3)\lor\cdots$

问题在于：**普通一阶逻辑的公式必须是有限长度的**，所以这种“无限合取/无限析取”不是合法的一阶逻辑公式。

因此可以这样记：

> $\forall$ 可以直观理解为“对论域中所有元素做合取”，$\exists$ 可以理解为“对所有元素做析取”；但只有论域有限时，才能真的展开成普通的一阶逻辑公式。

如果允许无限合取、无限析取，那就进入了更强的**无穷逻辑（infinitary logic）**。





__epsilon-delta就是无穷逻辑是吗？__

不是。

$\varepsilon$-$\delta$ 语言仍然是普通的一阶逻辑式量词表达，例如

$\forall \varepsilon>0,\ \exists \delta>0,\ \forall x,\quad |x-a|<\delta \Rightarrow |f(x)-L|<\varepsilon.$

虽然 $\varepsilon,\delta,x$ 都是在无限论域里取值，但公式本身仍然是有限长度的。

关键区别是：

- “在无限集合上使用 $\forall,\exists$”——完全属于普通一阶逻辑。

- “把 $\forall$ 真正展开成无限多个命题的合取”

  $P(a_1)\land P(a_2)\land P(a_3)\land\cdots$

  ——这才涉及无穷逻辑。

所以 $\varepsilon$-$\delta$ 的本质是：**用有限长度的量词，描述无限多个对象，而不是把它们无限展开。**

# CS70：Proofs 证明方法总结

## 1. 为什么需要“证明”？

实验、测试只能检查有限个例子，而计算机科学和数学经常讨论无限多个对象。

例如程序正确性：

$\forall x,\quad P(x)\text{ 的输出是正确的}$

你不可能把所有 $x$ 都运行一遍。因此需要用一个有限长度的逻辑推导，证明无限多个情况全部成立。

所以：

> **证明 = 用有限个严格的逻辑步骤，保证一个命题成立。**

这也是证明最核心的力量：有限步骤可以覆盖无限情况。

课堂转写也特别强调了这一点：程序验证、电路验证等问题本质上都涉及“如何确信对所有输入都正确”。

## 2. 基础记号

整数集合：

$\mathbb Z=\{\ldots,-2,-1,0,1,2,\ldots\}$

整除：

$a\mid b$

定义为：

$a\mid b \iff \exists q\in\mathbb Z,\quad b=aq$

例如：

$3\mid15$

因为

$15=3\times5$

证明中一个非常重要的技巧就是：

> **看到数学概念，先把它展开成定义。**

例如：

- $x$ 为偶数 $\Rightarrow x=2k$
- $x$ 为奇数 $\Rightarrow x=2k+1$
- $a\mid b\Rightarrow b=ak$

这往往就是证明的第一步。

------

# 3. 直接证明 Direct Proof

目标：

$P\Rightarrow Q$

套路就是：

$P \Rightarrow P_1 \Rightarrow P_2 \Rightarrow\cdots \Rightarrow Q$

即：

> 假设 $P$ 成立，然后一步一步推出 $Q$。

官方讲义将其概括为“Assume $P$，Therefore $Q$”。

### 例：整除

证明：

$a\mid b,\quad a\mid c \Rightarrow a\mid(b-c)$

由定义：

$b=aq_1,\qquad c=aq_2$

因此：

$b-c=a(q_1-q_2)$

又因为：

$q_1-q_2\in\mathbb Z$

所以：

$a\mid(b-c)$

本质就是：

> 展开定义 → 代数变形 → 回到目标的定义。

课堂转写正是用这个例子说明“从 $P$ 出发不断寻找中间命题，最后到达 $Q$”。

### 再例：奇数的平方仍为奇数

若：

$x=2a+1$

则：

$x^2=(2a+1)^2 =4a^2+4a+1 =2(2a^2+2a)+1$

因此 $x^2$ 是奇数。

------

# 4. 为什么这样能证明“所有整数”？

例如命题：

$\forall x\in\mathbb Z,\quad x\text{ 是奇数}\Rightarrow x^2\text{ 是奇数}$

证明过程中并没有选择：

$x=3,\quad x=5$

而是直接取一个**任意的**整数 $x$。

所以这个 $x$ 可以代表整个论域中的任何元素。

这就是：

> 证明全称命题 $\forall x$ 时，取一个任意的 $x$，证明它成立。

因此不是把无限多个情况一个个验证，而是一次证明整个模式。

------

# 5. 逆否证明 Proof by Contraposition

如果直接证明：

$P\Rightarrow Q$

很难，可以利用：

$P\Rightarrow Q \equiv \neg Q\Rightarrow\neg P$

所以改成证明：

$\neg Q\Rightarrow\neg P$

这叫**逆否证明**。

### 典型例子

设：

$d\mid n$

证明：

$n\text{ 为奇数} \Rightarrow d\text{ 为奇数}$

直接从“$n$ 是奇数”研究因子 $d$ 不太好下手。

于是证明逆否命题：

$d\text{ 为偶数} \Rightarrow n\text{ 为偶数}$

若：

$d=2k$

又因为：

$d\mid n$

所以：

$n=dl$

于是：

$n=(2k)l=2(kl)$

所以 $n$ 是偶数。

因此原命题成立。

课堂转写中的核心直觉就是：

> 正着走找不到 $P\to Q$ 的路，就尝试从 $\neg Q$ 反着走到 $\neg P$。

------

# 6. 反证法 Proof by Contradiction

要证明：

$P$

先假设：

$\neg P$

然后推出矛盾：

$R\land\neg R$

于是：

$\neg P$

不可能成立，所以 $P$ 成立。

结构：

$\neg P \Rightarrow\cdots \Rightarrow R$

同时：

$\neg P \Rightarrow\cdots \Rightarrow\neg R$

产生：

$R\land\neg R$

官方讲义指出，这背后依赖经典逻辑中的排中思想。

------

## 7. 经典反证：素数有无穷多个

目标：

> 证明素数有无穷多个。

假设相反：

> 素数只有有限多个。

全部列出：

$p_1,p_2,\ldots,p_k$

构造：

$q=p_1p_2\cdots p_k+1$

$q>1$，因此要么它自己是素数，要么存在素因子。

但所有素数按假设已经在：

$p_1,\ldots,p_k$

里面了。

假设某个 $p_i$ 整除 $q$：

$p_i\mid q$

同时：

$p_i\mid p_1p_2\cdots p_k$

于是：

$p_i\mid \left(q-p_1p_2\cdots p_k\right)$

即：

$p_i\mid1$

但素数不可能整除 $1$。

矛盾。

所以“一共只有有限多个素数”的假设错误，即：

$\boxed{\text{素数有无穷多个}}$



这里最值得记住的不是计算，而是那个构造：

$\boxed{q=p_1p_2\cdots p_k+1}$

“$+1$”保证它不能被列表中的任何一个素数整除。课堂对此花了大量时间解释这个构造背后的直觉。

------

# 8. 经典反证：$\sqrt2$ 是无理数

假设：

$\sqrt2=\frac ab$

其中 $a,b$ 已经约成最简分数，即：

$\gcd(a,b)=1$

平方：

$2=\frac{a^2}{b^2}$

所以：

$a^2=2b^2$

因此 $a^2$ 为偶数。

利用引理：

$a^2\text{ 为偶数} \Rightarrow a\text{ 为偶数}$

于是：

$a=2c$

代回：

$(2c)^2=2b^2$

得到：

$b^2=2c^2$

所以 $b$ 也为偶数。

于是 $a,b$ 都能被 $2$ 整除。

但开始已经假设：

$\gcd(a,b)=1$

矛盾。

因此：

$\boxed{\sqrt2\notin\mathbb Q}$



------

# 9. 分类讨论 Proof by Cases

有时候我们不知道哪一种情况成立，但知道：

$C_1\lor C_2\lor\cdots\lor C_n$

必然有一种成立。

如果分别证明：

$C_1\Rightarrow P$$C_2\Rightarrow P$$\cdots$

那么无论实际是哪种情况，都有 $P$。

因此 $P$ 成立。

## 10. 一个很漂亮的非构造证明

证明：

> 存在无理数 $x,y$，使得 $x^y$ 是有理数。

考虑：

$(\sqrt2)^{\sqrt2}$

只有两种情况。

### 情况 1

如果：

$(\sqrt2)^{\sqrt2}$

是有理数，

直接取：

$x=y=\sqrt2$

完成。

### 情况 2

如果：

$(\sqrt2)^{\sqrt2}$

是无理数，

取：

$x=(\sqrt2)^{\sqrt2}, \qquad y=\sqrt2$

则：

$x^y = \left((\sqrt2)^{\sqrt2}\right)^{\sqrt2} = (\sqrt2)^2 =2$

是有理数。

因此无论是哪种情况：

$\boxed{\exists x,y\notin\mathbb Q,\quad x^y\in\mathbb Q}$



有意思的是：

> 我们证明了这样的 $x,y$ **一定存在**，但这个证明本身并没有告诉我们究竟是哪一组。

这叫：

$\boxed{\text{非构造性证明（non-constructive proof）}}$

课堂转写最后讲的正是这个例子。

------

# 11. 全称命题和存在命题要特别区分

这是这一讲隐藏的一个重要主线。

证明：

$\forall x,\ P(x)$

必须说明**任意 $x$ 都成立**。

所以：

> 举一个例子没用。

但要反驳：

$\forall x,\ P(x)$

只需要一个反例：

$\exists x,\ \neg P(x)$

反过来，证明：

$\exists x,\ P(x)$

只需要找到一个满足条件的对象。

所以可以记成：

| 命题                  | 怎么证明              |
| --------------------- | --------------------- |
| $\forall x,P(x)$      | 取任意 $x$ 证明       |
| $\exists x,P(x)$      | 找一个 witness        |
| 否定 $\forall x,P(x)$ | 找一个反例            |
| 否定 $\exists x,P(x)$ | 证明所有 $x$ 都不满足 |

------

# 12. Lemma 和 Theorem

**Theorem（定理）**：你真正想证明、想得到的主要结论。

**Lemma（引理）**：为了证明更大的定理，提前证明的辅助结论。

例如证明 $\sqrt2$ 无理时：

$n^2\text{ 偶} \Rightarrow n\text{ 偶}$

就是一个引理。

CS70 的类比很直观：

> theorem 像最终功能，lemma 像可重复调用的子程序。

------

# 13. 常见证明错误

官方讲义特别强调三类坑：

第一，不要**假设自己正要证明的结论**。

想证明 $P$，不能：

$\text{Assume }P \Rightarrow\cdots$

然后说证明结束。

第二，小心除以 $0$。

例如已知：

$x=y$

那么：

$x-y=0$

所以绝不能约掉 $x-y$。

第三，不等式遇到负数要谨慎。

例如：

$-2<1$

不能直接平方得到：

$4<1$

；乘负数时，不等号方向还要反转。

# 14. 四种证明方法怎么选？

可以直接记这一张：

| 方法     | 思维方式                   | 适合情况                   |
| -------- | -------------------------- | -------------------------- |
| 直接证明 | $P\to\cdots\to Q$          | 从条件容易展开             |
| 逆否证明 | $\neg Q\to\cdots\to\neg P$ | 正着不好推，否定后结构简单 |
| 反证法   | 假设 $\neg P$，推出矛盾    | “不存在”“不可能”“无限”等   |
| 分类讨论 | 每种情况分别证明           | 有几个互斥/完备情况        |

一句话版：

$\boxed{ \begin{aligned} \text{直接：}&\quad P\to Q\\ \text{逆否：}&\quad \neg Q\to\neg P\\ \text{反证：}&\quad \neg P\to\bot\\ \text{分类：}&\quad C_1,C_2,\ldots\text{ 全覆盖} \end{aligned}}$

这也是这节课真正需要掌握的东西：不是背“素数无限”“$\sqrt2$ 无理”这些结论，而是理解这些证明背后的**逻辑结构和证明策略**。官方 Note 2 最后也明确强调了这一点。



__逆否证明的本质是否就是反证法？__

不完全是。

证明命题

$P\Rightarrow Q$

逆否证明是改证它的等价命题：

$\neg Q\Rightarrow \neg P.$

它本质上仍然是“直接证明另一个等价命题”。

而反证法通常是：先假设原命题不成立，即

$\neg(P\Rightarrow Q)\equiv P\land \neg Q,$

然后推出矛盾。

所以：

- 逆否证明：假设 $\neg Q$，推出 $\neg P$。
- 反证法：假设 $P$ 且 $\neg Q$，推出矛盾。

二者关系很近，而且逆否证明经常可以改写成反证法，但严格来说不是同一种证明方法。



__能不能给几个例子。__

可以。最清楚的方法是对同一个命题分别用“逆否证明”和“反证法”。

例 1：若 $n^2$ 是偶数，则 $n$ 是偶数。

逆否证明：原命题是

$n^2\text{ 是偶数}\Rightarrow n\text{ 是偶数}.$

逆否命题是

$n\text{ 是奇数}\Rightarrow n^2\text{ 是奇数}.$

设 $n=2k+1$，则

$n^2=(2k+1)^2=4k^2+4k+1=2(2k^2+2k)+1,$

所以 $n^2$ 是奇数。逆否命题成立，因此原命题成立。

反证法：假设原命题结论不成立，也就是假设

$n^2\text{ 是偶数},\qquad n\text{ 是奇数}.$

但 $n$ 是奇数会推出 $n^2$ 是奇数，与“$n^2$ 是偶数”矛盾。所以 $n$ 必须是偶数。

你会发现，两种证明非常像。区别在于：

$\text{逆否：}\quad \neg Q\Rightarrow\neg P$$\text{反证：}\quad P\land\neg Q\Rightarrow\bot$

例 2：若 $x^2<4$，则 $|x|<2$。

逆否证明：证明

$|x|\ge 2\Rightarrow x^2\ge4.$

因为 $|x|\ge2$，平方后直接得到

$x^2=|x|^2\ge4.$

所以原命题成立。

反证法：假设

$x^2<4$

但结论不成立，即

$|x|\ge2.$

于是

$x^2\ge4,$

与 $x^2<4$ 矛盾。

这个例子能很明显看出：逆否证明往往只是“换个方向之后更容易算”。

例 3：若整数 $ab$ 是奇数，则 $a,b$ 都是奇数。

逆否证明：逆否命题是

如果 $a,b$ 中至少有一个是偶数，那么 $ab$ 是偶数。

假设 $a$ 是偶数，则

$a=2k,$

所以

$ab=2kb,$

是偶数。同理 $b$ 是偶数也成立。因此原命题成立。

反证法：假设 $ab$ 是奇数，但 $a,b$ 不全是奇数。于是至少一个是偶数。假设 $a$ 偶，则 $ab$ 必然是偶数，与“$ab$ 是奇数”矛盾。

可以把区别记成一句话：

> 逆否证明是“换一个等价命题直接证”；反证法是“假设原命题错了，然后制造矛盾”。

形式上：

$P\Rightarrow Q$

逆否：

$\neg Q\Rightarrow\neg P$

反证：

$P\land\neg Q\Rightarrow\bot.$

因此它们逻辑上非常接近，但写证明时的起点不同。



__你这几个例子让我更觉得逆否证明和反证法是一个同构的关系了。__

对，你这个感觉其实很准确。更严格地说，在经典逻辑里，逆否证明和反证法对于证明 $P\Rightarrow Q$ 来说，核心推理结构几乎就是同一个。

逆否证明：

$\neg Q\Rightarrow \neg P$

而要证明 $\neg P$，本质上就是假设 $P$，然后推出矛盾：

$\neg Q,\ P\Rightarrow \bot.$

反证法则直接从：

$P,\ \neg Q\Rightarrow\bot$

开始。

所以两者展开以后实际上都是：

$\boxed{P,\neg Q\Rightarrow\bot}$

区别主要只是“包装方式”：

- 逆否证明：把 $\neg Q$ 当作前提，最后包装成 $\neg P$；
- 反证法：把 $P$ 和 $\neg Q$ 一起视为“原命题为假”的假设，然后推出矛盾。

因此你可以把它们理解成：

$\neg Q\Rightarrow\neg P \quad\Longleftrightarrow\quad (P\land\neg Q)\Rightarrow\bot.$

在经典逻辑中，这两种形式可以非常机械地互相转换。

不过数学上一般不会说它们“同构”，更准确会说它们在这里是逻辑等价、证明结构高度对应。

甚至可以进一步说：你刚才看到的几个例子之所以“怎么看都像同一种证明”，不是巧合——因为把逆否证明完全展开以后，内部那个最关键的步骤确实就是一次反证。







这一讲对应 CS70 的 **Note 3: Induction**。CS70 本身没有传统教材，官方 lecture notes 基本就是课程的主教材；这一讲的核心是普通归纳法、如何构造归纳命题、强归纳法，以及归纳证明为什么容易出错。([su18.eecs70.org](https://www.su18.eecs70.org/?utm_source=chatgpt.com))

# CS70：Mathematical Induction 数学归纳法

## 1. 归纳法到底在干什么？

目标通常是证明：

$\forall n\in\mathbb N,\quad P(n)$

但自然数有无穷多个，不可能：

$P(0),P(1),P(2),P(3),\dots$

一个个验证。

归纳法利用的是命题之间的“传递结构”：

$P(0)$

以及

$P(k)\Rightarrow P(k+1)$

一旦这两件事成立，就产生：

$P(0)\Rightarrow P(1)\Rightarrow P(2)\Rightarrow\cdots$

于是所有 $P(n)$ 都成立。

课堂用的直觉就是：

> 不是逐个处理无限多个情况，而是找到“从一个情况自动进入下一个情况”的通用机制。

------

# 2. 数学归纳法标准格式

要证明：

$\forall n\ge n_0,\quad P(n)$

一般分三步。

### Base Case：基础情况

证明：

$P(n_0)$

成立。

### Inductive Hypothesis：归纳假设

任取 $k\ge n_0$，假设：

$P(k)$

成立。

注意：

> 这里的 $P(k)$ 是暂时允许使用的条件，不需要重新证明。

### Inductive Step：归纳步骤

利用 $P(k)$，证明：

$P(k+1)$

即真正需要证明的是：

$P(k)\Rightarrow P(k+1)$

官方 Note 3 也是严格按照这三步定义归纳法的。([su17.eecs70.org](https://su17.eecs70.org/static/notes/n3.html?utm_source=chatgpt.com))

------

# 3. 多米诺骨牌理解

把：

$P(0),P(1),P(2),\dots$

想成无限排多米诺骨牌。

基础情况：

$P(0)$

就是：

> 推倒第一块。

归纳步骤：

$P(k)\Rightarrow P(k+1)$

就是：

> 保证每一块倒下都会撞倒下一块。

两者缺一不可。

所以：

$\boxed{ \text{基础情况负责启动，归纳步骤负责传播} }$

这也是课堂重点使用的直觉。

------

# 4. 经典例子：求和公式

证明：

$\sum_{i=0}^{n}i=\frac{n(n+1)}2$

### Base Case

$n=0$：

$0=\frac{0(0+1)}2$

成立。

### Inductive Hypothesis

假设：

$\sum_{i=0}^{k}i = \frac{k(k+1)}2$

### Inductive Step

考虑 $k+1$：

$\begin{aligned} \sum_{i=0}^{k+1}i &= \sum_{i=0}^{k}i+(k+1)\\ &= \frac{k(k+1)}2+(k+1)\\ &= \frac{(k+1)(k+2)}2 \end{aligned}$

正好就是：

$P(k+1)$

因此：

$\boxed{ \sum_{i=0}^{n}i=\frac{n(n+1)}2 }$

对所有自然数 $n$ 成立。

------

# 5. 归纳法最关键的一步：利用归纳假设

归纳步骤绝不是：

> 直接重新证明 $P(k+1)$。

而是：

> **把 $P(k+1)$ 改写成含有 $P(k)$ 的结构，然后调用归纳假设。**

例如：

$\sum_{i=0}^{k+1}i = \underbrace{\sum_{i=0}^{k}i}_{P(k)}+(k+1)$

这里真正聪明的地方就是把 $P(k)$ “挖出来”。

因此做归纳题时应该主动寻找：

$P(k+1) = \boxed{P(k)\text{ 相关部分}} + \text{额外部分}$

------

# 6. 整除型归纳证明

课堂证明了类似：

$3\mid(n^3+2n)$

的命题。

假设：

$3\mid(k^3+2k)$

考虑：

$(k+1)^3+2(k+1)$

展开：

$k^3+3k^2+3k+1+2k+2$

整理：

$=(k^3+2k)+3(k^2+k+1)$

第一项根据归纳假设可被 $3$ 整除；

第二项显然是 $3$ 的倍数。

因此整体可被 $3$ 整除。

这里再次体现同一个套路：

$P(k+1) = \underbrace{P(k)}_{\text{归纳假设}} + \underbrace{3(\cdots)}_{\text{显然成立}}$

顺带一提，部分版本的官方 Note 3 使用的是

$3\mid(n^3-n)$

两种命题都成立，而且两者相差 $3n$；课堂转写这一版讲的是 $n^3+2n$。([su17.eecs70.org](https://su17.eecs70.org/static/notes/n3.html?utm_source=chatgpt.com))

------

# 7. 归纳变量不一定是题目表面上的 $n$

这是这一讲一个很重要的思想。

例如课堂中的“地图二染色”问题。

地图由若干条不自行终止的曲线分割区域，要证明：

> 无论怎样画，都可以只用两种颜色，使共享边界的区域颜色不同。

这里应该对什么归纳？

不是：

- 区域数量；
- 颜色数量；

而是：

$\boxed{\text{曲线条数}}$

课堂专门强调了这个问题。

------

# 8. 地图二染色的归纳证明

设 $P(n)$：

> 用 $n$ 条允许的曲线形成的地图都可以二染色。

### Base Case

$n=0$。

没有曲线，显然可以。

### Inductive Hypothesis

假设任意 $k$ 条曲线形成的地图都能二染色。

### Inductive Step

现在有：

$k+1$

条曲线。

先删掉其中一条。

剩下 $k$ 条曲线，根据归纳假设，可以二染色。

然后把删掉的曲线加回来。

这条曲线把平面分成两侧。

将其中一侧：

$\text{红}\leftrightarrow\text{蓝}$

全部翻转。

这样：

- 新加入曲线两边颜色必然相反；
- 原来的曲线两侧如果都翻转，仍然颜色相反；
- 如果都没翻转，也仍然颜色相反。

因此 $k+1$ 条曲线也可以二染色。

这个例子说明：

> 归纳步骤不一定只是代数计算，也可以是对一个数学对象进行“删一个 → 用归纳假设 → 加回来 → 修复”的结构操作。

------

# 9. 归纳法真正难的地方：构造 $P(n)$

简单题会直接告诉你：

> 用归纳法证明 $P(n)$。

这种其实已经帮你做掉最难的一步了。

复杂问题中，你首先需要自己决定：

$\boxed{P(n)\text{ 到底应该是什么？}}$

课堂特别强调：

> 同一个问题，稍微修改一下归纳命题，证明难度可能完全不同。

因此归纳法不只是“Base Case + IH + Step”的模板。

真正的创造性经常在：

1. 对什么量归纳？
2. $P(n)$ 怎么定义？
3. 基础情况从哪里开始？
4. 归纳假设够不够强？

------

# 10. Strong Induction：强归纳法

普通归纳假设：

$P(k)$

强归纳假设：

$P(n_0),P(n_0+1),\dots,P(k)$

全部成立。

也就是：

$\boxed{ \bigwedge_{i=n_0}^{k}P(i) }$

然后证明：

$P(k+1)$

官方讲义明确指出，普通归纳和强归纳在“证明能力”上没有区别，只是强归纳有时候更方便。([EECS 70](https://www.sp18.eecs70.org/static/notes/n3.html?utm_source=chatgpt.com))

------

# 11. 多米诺理解强归纳

普通归纳：

> 第 $k$ 块骨牌负责推第 $k+1$ 块。

即：

$P(k)\Rightarrow P(k+1)$

强归纳：

> 推第 $k+1$ 块时，可以利用前面所有已经倒下的骨牌。

即：

$P(n_0)\land P(n_0+1)\land\cdots\land P(k) \Rightarrow P(k+1)$

课堂的表达很形象：

> 没必要规定一定是第 $k$ 块撞倒 $k+1$；前面的任何一块，甚至几块一起帮忙都可以。

------

# 12. 强归纳经典例子：整数的素因数分解

证明：

> 每个 $n\ge2$ 都能写成若干个素数的乘积。

定义：

$P(n): n\text{ 可以写成素数乘积}$

### Base Case

$n=2$。

$2$ 本身就是素数，所以成立。

### Strong Inductive Hypothesis

假设：

$P(2),P(3),\dots,P(k)$

全部成立。

证明：

$P(k+1)$

分两种情况。

### 情况一：$k+1$ 是素数

那么它本身已经是素数乘积。

完成。

### 情况二：$k+1$ 是合数

那么：

$k+1=ab$

其中：

$2\le a,b

所以：

$a,b\le k$

因此可以同时对 $a,b$ 使用强归纳假设：

$a=p_1p_2\cdots p_r$$b=q_1q_2\cdots q_s$

于是：

$k+1 = p_1\cdots p_rq_1\cdots q_s$

也是素数乘积。

所以结论成立。

------

# 13. 为什么这里普通归纳不好用？

因为：

$k+1=ab$

中的 $a,b$ 一般根本不是 $k$。

例如：

$100=10\times10$

要证明 $P(100)$，真正需要的可能是：

$P(10)$

而不是：

$P(99)$

所以只假设：

$P(k)$

不够方便。

而强归纳假设给你：

$P(2),P(3),\dots,P(k)$

于是需要哪个历史结果就调用哪个。

可以把强归纳理解成：

> **以前所有已经解决的小问题，现在都是你的工具。**

------

# 14. 普通归纳和强归纳不是两个不同的“公理”

它们证明能力等价。

普通归纳：

$P(k)\Rightarrow P(k+1)$

强归纳：

$P(0)\land\cdots\land P(k) \Rightarrow P(k+1)$

强归纳只是把“前面的全部结果已经成立”显式写进假设。

所以实践中：

> 如果 $P(k+1)$ 只需要 $P(k)$，普通归纳最简洁；
> 如果需要多个更小规模的结果，直接考虑强归纳。

官方讲义也明确说明二者证明能力完全相同。([EECS 70](https://www.sp18.eecs70.org/static/notes/n3.html?utm_source=chatgpt.com))

------

# 15. Base Case 不一定是 $0$

这是很容易误解的一点。

基础情况应该是：

$\boxed{\text{命题定义域中的第一个需要处理的情况}}$

例如：

$\forall n\ge2,\quad P(n)$

那 Base Case 就应该是：

$P(2)$

而不是 $P(0)$。

有时甚至需要验证多个基础情况：

$P(0),P(1),P(2)$

然后归纳步骤才能正常工作。

课堂也明确指出，有些证明可能必须先验证 $0,1,\dots,5$，一般性的归纳步骤才能启动。

------

# 16. 归纳证明为什么容易写出“假证明”？

归纳法很强，但也很危险。

最常见的问题是：

### 基础情况漏掉

你只证明：

$P(k)\Rightarrow P(k+1)$

并不能推出任何 $P(n)$ 真。

因为你没有推倒第一块骨牌。

### 归纳步骤偷偷用了还没证明的东西

你只能使用归纳假设允许你的内容。

普通归纳中只有：

$P(k)$

不能随便使用：

$P(k-1),P(k+2)$

除非已经证明它们可用。

### 归纳命题本身太弱

有时候真正需要证明一个更强的命题：

$Q(n)$

其中：

$Q(n)\Rightarrow P(n)$

虽然目标只是 $P(n)$，但更强的 $Q(n)$ 反而容易归纳。

这就是官方 Note 3 所说的：

> strengthening the induction hypothesis。

------

# 17. 巧克力问题

课堂最后提出：

一块 $m\times n$ 的巧克力共有：

$mn$

小块。

每次只能拿一块现有巧克力掰成两块。

最少需要多少次？

猜想：

$\boxed{mn-1}$

课堂本来试图用“双重强归纳”处理，但这一讲时间不够，没有完成严格证明。

这里不要把转写最后那段当成已经完成的证明——教授自己最后也停下来表示，需要下一讲重新整理双重归纳的形式。

不过这个问题其实还有一个极简不变量观点：

初始：

$1\text{ 块}$

每掰一次，块数只增加 $1$：

$1\to2\to3\to\cdots\to mn$

所以恰好需要：

$mn-1$

次。

这也很好地说明：

> **能用归纳法，不代表归纳法一定是最好的证明。**

------

# 18. 这一讲最重要的知识框架

可以压缩成：

$\boxed{ \begin{array}{c} \text{数学归纳法}\\[2mm] P(n_0)\\ +\\ P(k)\Rightarrow P(k+1)\\ \Downarrow\\ \forall n\ge n_0,\ P(n) \end{array}}$

强归纳则是：

$\boxed{ P(n_0),\dots,P(k) \Rightarrow P(k+1) }$

而做题时真正应该依次问：

1. **我要证明的 $P(n)$ 到底是什么？**
2. **对哪个量做归纳？**
3. **Base Case 从哪里开始？**
4. **证明 $P(k+1)$ 时，怎么把 $P(k)$ 挖出来？**
5. **只知道 $P(k)$ 够不够？**
6. 如果不够，是否应该改成**强归纳**或**加强归纳命题**？

其中第 1、2、4、6 点，才是 CS70 这一讲真正想训练的能力，而不只是背“Base Case → IH → Inductive Step”这个格式。([su17.eecs70.org](https://su17.eecs70.org/static/notes/n3.html?utm_source=chatgpt.com))
