可以。你现在最需要区分两类：

- “吸收律、分配律、交换律”属于等值律：左右两边逻辑等价，可以直接互换。
- “由 \(p,p\to q\) 推出 \(q\)”属于推理规则：从前提得到结论。

### 一、常用等值律

| 名称       | 公式                                                         |
| ---------- | ------------------------------------------------------------ |
| 双重否定律 | \(\neg\neg p\equiv p\)                                       |
| 交换律     | \(p\vee q\equiv q\vee p\)，\(p\land q\equiv q\land p\)       |
| 结合律     | \(p\vee(q\vee r)\equiv(p\vee q)\vee r\)，\(p\land(q\land r)\equiv(p\land q)\land r\) |
| 分配律     | \(p\land(q\vee r)\equiv(p\land q)\vee(p\land r)\)            |
|            | \(p\vee(q\land r)\equiv(p\vee q)\land(p\vee r)\)             |
| 德摩根律   | \(\neg(p\land q)\equiv\neg p\vee\neg q\)                     |
|            | \(\neg(p\vee q)\equiv\neg p\land\neg q\)                     |
| 吸收律     | \(p\vee(p\land q)\equiv p\)                                  |
|            | \(p\land(p\vee q)\equiv p\)                                  |
| 幂等律     | \(p\vee p\equiv p\)，\(p\land p\equiv p\)                    |
| 排中律     | \(p\vee\neg p\equiv1\)                                       |
| 矛盾律     | \(p\land\neg p\equiv0\)                                      |
| 恒等律     | \(p\vee0\equiv p\)，\(p\land1\equiv p\)                      |
| 支配律     | \(p\vee1\equiv1\)，\(p\land0\equiv0\)                        |
| 蕴含消去   | \(p\to q\equiv\neg p\vee q\)                                 |
| 等价消去   | \(p\leftrightarrow q\equiv(p\to q)\land(q\to p)\)            |
| 逆否律     | \(p\to q\equiv\neg q\to\neg p\)                              |

其中你做题最频繁用的是：

\[ \boxed{\text{蕴含消去、德摩根、分配、吸收、交换、结合}} \]

### 二、常用推理规则

| 名称        | 形式                                     |
| ----------- | ---------------------------------------- |
| 肯定前件 MP | \(p,\ p\to q\vdash q\)                   |
| 否定后件 MT | \(\neg q,\ p\to q\vdash\neg p\)          |
| 假言三段论  | \(p\to q,\ q\to r\vdash p\to r\)         |
| 析取三段论  | \(p\vee q,\ \neg p\vdash q\)             |
| 合取引入    | \(p,\ q\vdash p\land q\)                 |
| 合取消去    | \(p\land q\vdash p\)                     |
| 析取引入    | \(p\vdash p\vee q\)                      |
| 分类讨论    | \(p\vee q,\ p\to r,\ q\to r\vdash r\)    |
| 归结规则    | \(p\vee q,\ \neg p\vee r\vdash q\vee r\) |

你刚才 Problem 8 用的就是：

\[ \boxed{p\vee q,\quad p\to r,\quad q\to r\vdash r} \]

也就是“分类讨论”。

一个很实用的记忆框架是：

\[ \boxed{ \begin{array}{c} \text{化公式：蕴含消去}\to\text{德摩根}\to\text{分配/吸收}\\ \text{做证明：MP、MT、三段论、分类讨论} \end{array}} \]

这套基本足够覆盖你当前形式逻辑作业的大部分题。
