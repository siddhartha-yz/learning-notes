### 极简回顾一下深度学习中的inception

Inception：**同一层并行使用不同大小的卷积核，再把结果拼起来。**

典型结构：

```text
输入
 ├─ 1×1 卷积
 ├─ 3×3 卷积
 ├─ 5×5 卷积
 └─ 池化
      ↓
按通道拼接
```

目的：

- 同时提取不同尺度的特征
- 让网络自己决定更需要哪种感受野
- `1×1` 卷积常用来先降通道数，减少计算量

一句话：

> Inception = 多种卷积并行提特征，再把它们拼起来。

### 极简解释一下dampening

`dampening` 常见于带 momentum 的 SGD，意思是：**削弱当前梯度对动量的贡献。**

常见形式：

$v_t=\mu v_{t-1}+(1-d)g_t$

其中：

- $\mu$：momentum
- $d$：dampening
- $g_t$：当前梯度

直觉：

> dampening 越大，当前这一步的梯度对“惯性”的影响越小。

PyTorch 里：

```python
torch.optim.SGD(..., momentum=0.9, dampening=0.1)
```

表示当前梯度只按 `0.9` 倍加入 momentum。

### 极简回顾一下weight decay

Weight decay：**在训练时额外惩罚过大的权重，让参数不要变得太大。**

常见形式：

$L' = L + \lambda \sum w^2$

效果：

- 抑制过拟合
- 让模型更平滑、更简单
- 本质上常对应 L2 正则化

直觉：

> 权重越大，罚得越狠。

### 极简回顾softmax

Softmax：把一组任意实数分数，转换成总和为 1 的概率分布。

公式：

$p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}$

例如：

```text
scores = [2, 1, 0]
↓ softmax
prob   ≈ [0.665, 0.245, 0.090]
```

特点：

- 每个值都在 $0\sim1$
- 所有概率之和为 1
- 分数越大，对应概率越大

常用于多分类问题的输出层。

### 深度学习中rollout什么意思

Rollout：让模型或策略从当前状态开始，连续执行若干步，生成一整段未来轨迹。

常见于强化学习、Agent、world model。

例如：

```text
当前状态 s0
→ 动作 a0
→ 状态 s1
→ 动作 a1
→ 状态 s2
→ ...
```

这整段过程就是一次 rollout。

用途通常是：

- 评估当前策略效果
- 收集训练数据
- 在模型内部“想象”未来结果
- 计算累计奖励 return

一句话：

> rollout = 把策略真正往前跑一段，看后面会发生什么。

### 感觉有点像前向传播。

对，直觉上有点像，但层级不同。

前向传播：

```text
输入
→ 一层层计算
→ 得到这一次输出
```

Rollout：

```text
当前状态
→ 模型输出动作/下一状态
→ 再把结果作为下一步输入
→ 连续重复很多步
```

所以可以理解为：

> 前向传播通常是“一次计算”，rollout 是“连续做很多次前向计算，形成一条轨迹”。

尤其在 world model 里，这种感觉很明显。

### 交叉熵越小，说明预测越好；交叉熵越大，损失越大。

以正确类别的预测概率 $p$ 为例：

$L=-\log p$

所以：

```text
p 越接近 1 → -log(p) 越小 → loss 越小
p 越接近 0 → -log(p) 越大 → loss 越大
```

例如：

```text
正确类别概率 0.9 → loss ≈ 0.105
正确类别概率 0.1 → loss ≈ 2.303
```

一句话：**模型越确信正确答案，交叉熵越小。**
