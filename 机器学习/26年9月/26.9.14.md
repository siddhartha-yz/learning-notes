# 深度循环神经网络

这节讲的是：把单层 RNN/LSTM/GRU 纵向堆叠起来，形成“深度循环神经网络”。核心目的和普通神经网络加深类似：提升模型表达能力。([动手学深度学习](https://zh.d2l.ai/chapter_recurrent-modern/deep-rnn.html))

最重要的是理解这张逻辑图：

```text
时间 →
t-1        t          t+1

第2层   H² ─────→ H² ─────→ H²
          ↑         ↑         ↑
第1层   H¹ ─────→ H¹ ─────→ H¹
          ↑         ↑         ↑
输入     X         X         X
```

一个隐藏状态有两个流向：

1. 横向：传给同一层的下一个时间步。
2. 纵向：传给当前时间步的上一层。

所以深度 RNN 同时有两种“深度”：

- 时间方向的深度：处理序列前后关系。
- 网络层数方向的深度：逐层提取更复杂的特征。([动手学深度学习](https://zh.d2l.ai/chapter_recurrent-modern/deep-rnn.html))

数学上，第 $l$ 层在时间 $t$ 的隐藏状态：

$H_t^{(l)} = \phi_l( H_t^{(l-1)}W_{xh}^{(l)} + H_{t-1}^{(l)}W_{hh}^{(l)} + b_h^{(l)} )$

不用死记。直觉就是：

> 当前层的新隐藏状态 = 当前时间来自下一层输入的信息 + 自己上一时间步的记忆。

其中：

```text
H_t^(l-1)  → 来自下面一层的信息
H_(t-1)^l  → 自己上一时刻的记忆
H_t^l      → 当前的新记忆
```

最终只有最顶层的隐藏状态拿去计算输出：

$O_t = H_t^{(L)}W_{hq}+b_q$

也就是：

```text
输入
 ↓
RNN 第1层
 ↓
RNN 第2层
 ↓
...
 ↓
RNN 第L层
 ↓
输出
```

这里的每一层不一定是普通 RNN，也可以换成 GRU 或 LSTM，因此就有：

- Deep RNN
- Deep GRU
- Deep LSTM ([动手学深度学习](https://zh.d2l.ai/chapter_recurrent-modern/deep-rnn.html))

PyTorch 实现反而非常简单。比如两层 LSTM：

```python
nn.LSTM(
    num_inputs,
    num_hiddens,
    num_layers=2
)
```

D2L 示例本质上就是把：

```python
num_layers = 1
```

改成：

```python
num_layers = 2
```

高级 API 已经帮你处理好了层与层之间的连接。([动手学深度学习](https://zh.d2l.ai/chapter_recurrent-modern/deep-rnn.html))

这一节你真正需要记住的只有一句：

> 深度 RNN = 在“时间方向循环”的基础上，再在“层方向”堆叠多个 RNN。

可以把普通 RNN 理解为：

```text
时间上很长，纵向只有一层
```

而 Deep RNN 是：

```text
时间上很长
+
纵向也有很多层
```

代价也很明显：层数增加后计算量更大、训练更慢，也更需要仔细调学习率、梯度裁剪和初始化。D2L 的两层 LSTM 示例就明确指出训练速度明显下降。([动手学深度学习](https://zh.d2l.ai/chapter_recurrent-modern/deep-rnn.html))

如果按你现在学 D2L 的进度，这一节理解到“横向传记忆，纵向传特征”就已经足够了。
