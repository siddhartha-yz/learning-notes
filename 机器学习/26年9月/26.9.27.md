# 自注意力和位置编码

这一节可以直接压成两件事：Self-Attention + 位置编码。

Self-Attention 的核心：

> 一句话里的每个 token，都可以直接去看这句话里的所有 token。

以前 RNN 是：

```
x1 → x2 → x3 → x4
```

信息要一层层传。

Self-Attention 则是：

```
x1 ↔ x2 ↔ x3 ↔ x4
```

每个位置都可以直接和所有位置交互。教材里把每个输入同时作为 Query，并把整组输入作为 Key/Value 集合。[动手学深度学习](https://zh.d2l.ai/chapter_attention-mechanisms/self-attention-and-positional-encoding.html)

如果输入矩阵是 \(X\)，就做：

\[ Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V \]

然后：

\[ A=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt d}\right) \]\[ Y=AV \]

直觉就是：

```
QK^T
↓
“我应该关注谁？”

softmax
↓
“分别关注多少？”

× V
↓
“把那些位置的信息拿过来”
```

所以经过一层 Self-Attention 后，每个 token 的输出都已经混入了其他 token 的信息。

它相对 RNN 最大的优势有两个：

```
RNN：
token1 的信息到 token100
要经过很长的递归链

Self-Attention：
token1 ↔ token100
一次就能直接交互
```

而且所有位置可以一起矩阵计算，不必像 RNN 一样等前一个时间步算完，所以非常适合 GPU 并行。教材也对比了 RNN、CNN、自注意力的计算复杂度和最长路径长度。[动手学深度学习](https://zh.d2l.ai/chapter_attention-mechanisms/self-attention-and-positional-encoding.html)

但 Self-Attention 马上产生一个新问题：

> 它本身没有天然的“先后顺序”。

RNN 天然知道：

```
我 → 爱 → 你
```

因为它是按顺序处理的。

Self-Attention 却更像：

```
{我, 爱, 你}
```

它主要知道“谁和谁相关”，但不天然知道谁第 1、第 2、第 3。

所以要加 Positional Encoding：

\[ X'=X+P \]

也就是：

```
token embedding
+
position embedding
```

例如：

```
“我”的语义 + 第1位
“爱”的语义 + 第2位
“你”的语义 + 第3位
```

这样模型既知道“这是什么词”，又知道“它在哪”。D2L 这里使用的是经典 Transformer 的正弦/余弦位置编码。[动手学深度学习](https://zh.d2l.ai/chapter_attention-mechanisms/self-attention-and-positional-encoding.html)

公式是：

\[ P_{i,2j} = \sin\left(\frac{i}{10000^{2j/d}}\right) \]\[ P_{i,2j+1} = \cos\left(\frac{i}{10000^{2j/d}}\right) \]

不用背。直觉就是：

> 不同维度用不同频率的波，给每个位置生成一个独特的“位置指纹”。

有的维度变化很快，有的很慢，组合起来就能区分位置，并且还能比较方便地表达相对距离。[动手学深度学习](https://zh.d2l.ai/chapter_attention-mechanisms/self-attention-and-positional-encoding.html)

整节最核心的逻辑链：

```
RNN
↓
有顺序
但串行、长距离信息传递慢

Self-Attention
↓
所有 token 直接互相看
并行、长距离一步连接

但是
↓
顺序感没了

所以
↓
加位置编码
```

一句话记忆：

> Self-Attention 负责“谁该看谁”，位置编码负责“谁在什么位置”。
