# 循环神经网络

## 通过时间反向传播

### 比较策略

三种 BPTT 策略：

- 随机截断：每次截断长度随机，理论上更接近真实梯度，但训练方差大。
- 常规截断：固定长度截断，最常用，计算稳定、带轻微正则化效果。
- 完整 BPTT：整条序列反传，理论最完整，但计算和显存代价太大，也更容易梯度不稳定。

一句话：

> 实践中通常选固定长度的截断 BPTT，因为最稳定、最实用。

### 为什么随机截断好像看起来有正则化的作用，比如减弱固定步数截断对权重的影响，但却实际效果并不好？实际效果不好在哪？

对，随机截断确实带有一点“随机正则化”的味道，但它的问题是：噪声太大，已经不只是适度正则化了。

核心区别：

> 好的正则化 = 给训练加入适量噪声，但梯度方向总体仍然稳定。
> 随机截断 = 梯度估计虽然理论上无偏，但方差可能非常大。

随机截断为了保证期望上等于完整 BPTT，会出现这种情况：

```text
大多数时候：
只反传很短距离 → 梯度贡献小

偶尔：
反传很长距离 → 必须给这条梯度很大的权重补偿
```

于是训练时可能出现：

```text
这一步梯度很小
下一步也很小
突然某一步梯度巨大
再下一步又很小
```

这会导致：

- 参数更新剧烈抖动；
- 收敛速度慢；
- 对学习率非常敏感；
- 更容易出现梯度爆炸；
- 每次计算长度不同，也不利于高效批处理。

所以它的问题不是“有随机性”，而是：

> 随机性带来的梯度方差太大，优化器很难得到稳定的下降方向。

相比之下，固定长度截断虽然是有偏的——比如永远只看最近 50 步——但每次梯度的统计性质更稳定，训练通常反而更好。

一句话：

> 随机截断理论更漂亮（无偏），固定截断工程上更好用（低方差、稳定）。

### 那我给随机截断一个更高的约束不就行了？比如高斯分布减少他的方差。

__关键词：“无偏”，“有偏”__

可以，这个思路是成立的，但有个关键区别：

> “截断长度的方差小”不等于“梯度估计的方差小”。

比如你让截断长度集中在 50 附近：

$\tau \sim \mathcal N(50,\sigma^2)$

并把 $\sigma$ 设得很小，那么确实会变成：

```text
大多数：48~52 步
偶尔：稍长或稍短
```

这会比完全随机的截断稳定很多。

但问题是：如果你还想保持“期望上等于完整 BPTT”的无偏性质，那么那些非常罕见的长距离梯度仍然需要被赋予较大的补偿权重。真正导致高方差的往往正是这些权重，而不仅仅是截断长度本身。

如果你进一步限制：

> 最多只允许 60 步，不允许更长。

那训练当然稳定了，但 60 步之外的梯度永远消失，于是又变成了“有偏的截断 BPTT”。

所以存在一个基本权衡：

```text
限制越强
→ 方差越小、训练越稳定
→ 越接近普通固定截断
→ 长距离 credit assignment 越弱

限制越松
→ 理论上更接近完整 BPTT
→ 但梯度方差和计算量更大
```

因此你的想法不是错，而是实际做下去会自然滑向一个结论：

> “稍微随机化的固定截断”可以做，但如果为了稳定性把随机范围限制得很窄，它和普通 TBPTT 的区别也就越来越小了。

### 那这不是一个方差——偏差权衡吗？

对，本质上就是一种“偏差—方差权衡”，不过这里说的是梯度估计的 bias–variance tradeoff，不是通常泛化理论里的模型偏差—方差。

可以这样看：

- 完整 BPTT：偏差最低，但计算贵，而且梯度可能很不稳定。
- 固定截断 BPTT：梯度有偏，但方差较小、训练稳定。
- 随机截断：可以做到期望上无偏，但往往梯度方差很大。

所以工程上常接受一点偏差，换取更低方差和更稳定的优化。

一句话：

> TBPTT 的核心取舍就是：牺牲一点梯度无偏性，换取计算效率和低方差。

### 我靠，我好像终于有点懂rnn了。其实整套rnn下来参数并不多。我之前理解成了类似于残差那样的结构。但是残差不是参数共享的了。这样估计下来其实rnn就3套参数，输入，处理，输出。每一层rnn都复用这三套参数。这也是为什么rnn极易梯度消失或者梯度爆炸的原因是吗？

对，你现在的整体理解已经接近了，但有一处要修正：

> RNN 是“时间步之间共享参数”，不是“不同 RNN 层之间共享参数”。

最简单的单层 RNN，核心确实可以看成三套权重：

- $W_{xh}$：输入 → 隐藏状态
- $W_{hh}$：旧隐藏状态 → 新隐藏状态
- $W_{hq}$：隐藏状态 → 输出

然后无论序列有 10 个还是 1000 个 token，都反复使用这几套参数：

```text
x1 → h1 → y1
     ↓
x2 → h2 → y2
     ↓
x3 → h3 → y3
...
```

其中每一步都使用同一个 $W_{hh}$。

如果是多层 RNN：

```text
第2层：自己的 W_xh²、W_hh²
          ↑
第1层：自己的 W_xh¹、W_hh¹
```

不同网络层一般有自己的参数，但每一层自己的参数会沿时间反复复用。

你关于梯度消失/爆炸的判断也基本对。

反向传播穿过很多时间步时，会反复乘类似：

$W_{hh}$

以及激活函数导数，因此出现长连乘：

$\frac{\partial h_t}{\partial h_{t-k}} = \prod \frac{\partial h_i}{\partial h_{i-1}}$

如果这些乘数整体偏小：

> 越乘越接近 0 → 梯度消失。

如果整体偏大：

> 越乘越大 → 梯度爆炸。

所以更准确地说：

> 不是因为 RNN“参数少”才容易梯度消失/爆炸，而是因为同一个递归变换沿时间反复作用，反向传播时产生很长的 Jacobian 连乘。

这也是后来 LSTM、GRU 要重点解决的问题之一。

### 可我看这个rnn讲解视频，yesterday today tomorrow都是共用w1,w2,w3的啊？

对，这张图正是在说明：Yesterday / Today / Tomorrow 这三个时间步共用同一套 $W_1,W_2,W_3$。

关键是：

> Yesterday、Today、Tomorrow 不是三个不同的 RNN 隐藏层，而是同一个 RNN 单元在三个不同时间步上的“展开”。

图里大致可以对应成：

- $W_1$：当前输入 → 隐藏状态
- $W_2$：上一时间步隐藏状态 → 当前隐藏状态
- $W_3$：隐藏状态 → 输出

所以：

```text
Yesterday:
x₁ --W1--> h₁ --W3--> y₁
              |
             W2
              ↓

Today:
x₂ --W1--> h₂ --W3--> y₂
              |
             W2
              ↓

Tomorrow:
x₃ --W1--> h₃ --W3--> y₃
```

这里三个时间步里的 $W_1$ 是同一个参数对象，$W_2$ 也是同一个，$W_3$ 也是同一个。

所以你刚才理解的：

> RNN 参数其实不多，同一套参数沿时间反复使用。

是完全正确的。

我之前说“多层 RNN 每层有自己的一套参数”，说的是另一维：

```text
纵向：RNN 第1层、第2层、第3层
→ 不同层通常参数不同

横向：Yesterday → Today → Tomorrow
→ 同一层在所有时间步参数共享
```

你截图展示的是横向的“时间展开”，不是纵向的“网络深度”。

### 从这张图来看，时间步也是一个二维的结构，只是输出被隐藏了。虽然不太懂为什么隐藏，“隐藏”又是什么意思。

你这里有一半理解对了，但“二维结构”只是图的画法，不是 RNN 本身有二维空间结构。

每个时间步真正做的是：

$h_t=\phi(x_tW_{xh}+h_{t-1}W_{hh}+b_h)$

然后：

$o_t=h_tW_{ho}+b_o$

所以每个时间步都可以理解成：

```text
当前输入 x_t
      ↓
   [ RNN ]
   ↑     ↓
h_{t-1}  h_t
          ├──→ 下一时间步
          └──→ 输出 o_t
```

这里的 $h_t$ 就是“隐藏状态”。

“隐藏”并不是说它被程序藏起来、不让你看到，也不是说“输出被隐藏了”。

它真正的意思是：

> 这是模型内部自己产生的中间表示，不是数据中直接观测到的变量。

比如天气数据里你能直接看到：

```text
温度、湿度、降雨量
```

这些是观测变量。

而 RNN 内部可能形成一个向量 $h_t$，其中编码了“最近似乎处于降温趋势”“前几天持续下雨”等信息。但数据集并没有给你这个 $h_t$，它是模型自己学出来的，所以叫 hidden state。

而且 $h_t$ 并不是不用：

- 它传给下一个时间步，充当“记忆”
- 它也可以拿去计算当前输出

所以更准确地理解：

> hidden = 内部潜在表示，而不是“被隐藏不用的输出”。

你截图里的 $y_1,y_2,y_3$ 更像是每个时间步内部的隐藏激活，而右边 `Predicted Value` 才是真正对外的预测输出。

### 我突然意识到，动态数量变化的网络是不是rnn的关键创新？

可以把“能处理动态长度的序列”看成 RNN 的重要能力，但不是它最核心的创新。

更准确地说，RNN 的关键是：

> 同一个计算单元反复作用于不同时间步，并通过隐藏状态把过去的信息传到未来。

所以当输入长度变化时：

```text
3 个 token → RNN 调用 3 次
10 个 token → RNN 调用 10 次
100 个 token → RNN 调用 100 次
```

看起来“展开后的网络长度”动态变化，但真正的模型参数没有增加，始终复用同一套参数。

因此不要理解成：

> 网络本身动态长出新的参数或新的层。

而应该理解成：

> 固定的 RNN 单元被动态调用若干次。

所以 RNN 的核心创新更接近：

> 递归状态 + 时间步参数共享 → 让固定参数的模型可以处理任意长度序列。

### 小结

“通过时间反向传播”仅仅适用于反向传播在具有隐状态的序列模型。

截断是计算方便性和数值稳定性的需要。截断包括：规则截断和随机截断。

矩阵的高次幂可能导致神经网络特征值的发散或消失，将以梯度爆炸或梯度消失的形式表现。

为了计算的效率，“通过时间反向传播”在计算期间会缓存中间值。

# 现代循环神经网络

## 门控循环单元（GRU）

GRU 是为了解决普通 RNN 的长期记忆和梯度问题。

它主要想做到三件事：

- 重要的旧信息：长期保留。
- 无关的新信息：可以跳过。
- 遇到新段落/新语境：可以重置部分记忆。

本质上：

> GRU 给 RNN 加了“门”，让模型自己决定哪些信息该记、该忘、该更新。

它可以看作 LSTM 的简化版，通常参数更少、计算更快。

### 门控隐状态

门控隐状态就是：给 RNN 的隐藏状态加“开关”。

模型会自己学会：

- 什么时候保留旧记忆
- 什么时候加入新信息
- 什么时候丢掉/重置旧信息

所以普通 RNN 是：

$h_t=f(x_t,h_{t-1})$

而 GRU 会多出几个“门”，控制 $h_{t-1}$ 到底有多少应该保留。

一句话：

> GRU 的“门控”就是让隐藏状态不再每一步都被强制重写，而是学会有选择地记、忘、更新。

### 重置门和更新门

这页只是在定义 GRU 的两个“门”：重置门 $R_t$ 和更新门 $Z_t$。

先抓住一个核心：

> “门”不是 0/1 的硬开关，而是一组介于 0 和 1 之间的数，用来控制信息通过多少。

例如一个门可能是：

$[0.9,\ 0.1,\ 0.7]$

可以粗略理解成：

```text
第1维：保留很多
第2维：几乎挡住
第3维：保留较多
```

在时间步 $t$，GRU 手上有两样东西：

```text
当前输入 X_t
+
上一时刻记忆 H_{t-1}
```

然后分别拿它们计算两个门。

重置门：

$R_t = \sigma( X_tW_{xr} + H_{t-1}W_{hr} + b_r )$

更新门：

$Z_t = \sigma( X_tW_{xz} + H_{t-1}W_{hz} + b_z )$

因为最后经过 sigmoid：

$0

所以它们天然可以充当“信息阀门”。

两扇门分别干什么？

重置门 $R_t$：

> 决定计算“新的候选记忆”时，要参考多少旧记忆。

直觉上：

```text
R_t ≈ 0
→ 旧记忆基本不要
→ 更像“重新开始”

R_t ≈ 1
→ 大量参考旧记忆
```

所以叫“重置门”。

更新门 $Z_t$：

> 决定最终隐藏状态里，旧记忆保留多少、新记忆写入多少。

直觉上：

```text
Z_t 很大
→ 更倾向保留旧状态

Z_t 很小
→ 更倾向用新状态覆盖旧状态
```

所以叫“更新门”。

你可以先把 GRU 想成：

```text
                    ┌→ 重置门 R_t
当前输入 X_t ───────┤
上一记忆 H_{t-1} ──┤
                    └→ 更新门 Z_t

R_t：旧记忆参与“生成新信息”多少
Z_t：最终“旧信息 vs 新信息”各保留多少
```

这页最重要的一点是：

> 两个门本身也是神经网络算出来的，而且它们的参数同样通过反向传播学习。

也就是说，模型不是人工规定“这个词该忘、那个词该记”，而是自己学会什么时候该记、什么时候该忘。

### 候选隐状态

这里是在讲：GRU 最后到底怎么把“旧记忆”和“新记忆”合成当前隐藏状态。

前一步其实已经算出了两个东西：

- 旧隐藏状态 $H_{t-1}$：上一时刻留下来的记忆
- 候选隐藏状态 $\tilde H_t$：根据当前输入 $X_t$ 和部分旧记忆算出来的“新方案”

现在更新门 $Z_t$ 决定：

> 旧记忆保留多少，新记忆写入多少。

最终公式是：

$H_t = Z_t\odot H_{t-1} + (1-Z_t)\odot \tilde H_t$

可以直接把它理解成“加权平均”。

比如某一维上：

$Z_t=0.9$

那么：

$H_t = 0.9H_{t-1} + 0.1\tilde H_t$

也就是：

> 90% 保留旧记忆，只写入 10% 新信息。

如果：

$Z_t=0.1$

那么：

$H_t = 0.1H_{t-1} + 0.9\tilde H_t$

也就是：

> 基本丢掉旧记忆，大量采用新信息。

所以更新门可以看成一个“记忆更新旋钮”：

```text
Z_t 接近 1
→ 旧记忆保留
→ 当前输入影响较小

Z_t 接近 0
→ 大量写入新记忆
→ 旧记忆被替换
```

这为什么能缓解 RNN 的长期依赖问题？

因为如果某条信息很重要，GRU 可以连续很多时间步让 $Z_t$ 接近 1：

```text
重要记忆
h1 → h2 → h3 → h4 → ... → h100
     几乎原样保留
```

这样信息就不需要每一步都重新经过复杂的非线性变换，更容易长期保存，梯度也更容易沿这条路径传播。

而重置门 $R_t$ 和更新门 $Z_t$ 的分工可以这样记：

- $R_t$：算“新记忆”时，要参考多少旧记忆
- $Z_t$：最终结果里，旧记忆和新记忆各占多少

一句话：

> 重置门负责“怎么产生候选新记忆”，更新门负责“旧记忆和新记忆最后怎么混合”。

### 我怎么觉得重置门的作用被更新门包含了呢？

你的感觉有道理，因为两者都在控制“旧信息”，所以功能确实有部分重叠，但不完全一样。

关键区别在于它们作用的阶段不同。

重置门 $R_t$ 作用在“生成候选新记忆”之前：

$\tilde H_t = \tanh\left( X_tW_{xh} + (R_t\odot H_{t-1})W_{hh} +b \right)$

它回答的是：

> “我在思考新的内容时，要参考多少过去？”

而更新门 $Z_t$ 作用在候选记忆已经算出来之后：

$H_t = Z_t\odot H_{t-1} + (1-Z_t)\odot\tilde H_t$

它回答的是：

> “最终状态里，旧记忆和新记忆各占多少？”

所以可以记成：

```text
旧记忆 H_{t-1}
     ↓
重置门：新内容计算时参考多少旧记忆？
     ↓
候选新记忆 H̃_t
     ↓
更新门：最终旧记忆和新记忆怎么混？
     ↓
H_t
```

举个直观例子：进入一个新句子时，模型可能希望“计算新语义时别参考上一句”——此时重置门可以很小；但它同时可能仍希望最终隐藏状态保留一点上一句的重要信息——此时更新门仍可以保留部分旧状态。

所以：

> 重置门控制“旧信息如何参与生成新信息”，更新门控制“最终保留多少旧信息”。

不过你觉得它们有冗余也不是错的：确实有一些简化 GRU 的结构会去掉重置门，说明它不是绝对不可替代，只是两个门一起会提供更灵活的控制能力。

### 我感觉这里已经有一点attention的味道了，只是attention是嵌入之后，利用词向量的点积来控制旧信息与新信息的比重的，不是吗？

有一点相似的“选择性保留信息”味道，但机制不一样。

GRU 的门控是在做：

> 旧隐藏状态和新候选状态之间，按比例混合。

比如更新门：

$H_t = Z_t\odot H_{t-1} + (1-Z_t)\odot \tilde H_t$

它是在决定“旧记忆留多少，新记忆写多少”。

Attention 更像：

> 当前 token 应该从历史 token 里重点读取谁的信息。

典型 self-attention 先算相关性：

$QK^\top$

再经过 softmax 得到权重：

$\alpha_{ij}$

最后做加权求和：

$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\left(\frac{QK^\top}{\sqrt d}\right)V$

直觉上：

```text
GRU：
旧记忆 vs 新记忆
→ 控制“保留比例”

Attention：
过去有很多 token
→ 控制“我现在重点看谁”
```

所以你的类比有道理，但更准确地说：

> GRU 的门是“时间递归中的信息阀门”；Attention 是“在一堆信息源之间动态分配读取权重”。

另外，Attention 也不一定只是“词向量直接点积”，通常是先把表示分别投影成 $Q,K,V$，再用 $Q$ 和 $K$ 的点积计算相关性。

### 小结

门控循环神经网络可以更好地捕获时间步距离很长的序列上的依赖关系。

重置门有助于捕获序列中的短期依赖关系。

更新门有助于捕获序列中的长期依赖关系。

重置门打开时，门控循环单元包含基本循环神经网络；更新门打开时，门控循环单元可以跳过子序列。

### 为什么：

1. 重置门有助于捕获序列中的短期依赖关系。
2. 更新门有助于捕获序列中的长期依赖关系。

顺便解释一下：
重置门打开时，门控循环单元包含基本循环神经网络；更新门打开时，门控循环单元可以跳过子序列。

关键是看两个门分别“控制哪条路”。

重置门 $R_t$ 控制的是：计算候选新状态时，要不要参考旧状态。

$\tilde H_t = \tanh\left( X_tW_{xh} + (R_t\odot H_{t-1})W_{hh} +b \right)$

当 $R_t\approx 0$：

> 基本不看过去，主要根据当前输入重新计算。

所以可以迅速“忘掉很久以前的信息”，更关注当前附近的信息，因此有利于短期依赖。

当 $R_t\approx 1$：

$R_t\odot H_{t-1}\approx H_{t-1}$

公式就退化得很像普通 RNN：

$\tilde H_t \approx \tanh(X_tW_{xh}+H_{t-1}W_{hh}+b)$

所以教材说：

> 重置门打开时，GRU 包含基本 RNN。

这里“打开”就是让旧隐藏状态完整通过。

------

更新门 $Z_t$ 控制的是：最终状态到底保留多少旧记忆。

$H_t = Z_t\odot H_{t-1} + (1-Z_t)\odot\tilde H_t$

当 $Z_t\approx1$：

$H_t\approx H_{t-1}$

当前的新信息几乎不写入，旧状态直接复制过去：

```text
h₁ → h₂ → h₃ → h₄
几乎原样传递
```

所以即使中间经过很多无关 token，也可以把很早的信息一直保存下来。

这就是为什么更新门有利于长期依赖。

教材所谓：

> 更新门打开时，可以跳过子序列。

意思就是假设连续几十步都有 $Z_t\approx1$：

```text
重要信息 h₁
   ↓
h₂ ≈ h₁
   ↓
h₃ ≈ h₂
   ↓
h₄ ≈ h₃
...
```

中间这些 token 基本没有修改隐藏状态，相当于“跳过”了这段子序列。

所以一句话记：

- 重置门：控制“算新记忆时，要看多少过去” → 容易重新开始 → 短期依赖。
- 更新门：控制“旧记忆要保存多久” → 可以长期原样传递 → 长期依赖。

而且更新门能缓解梯度消失也正因为 $H_{t-1}\rightarrow H_t$ 存在这种近似恒等的直通路径。

## 长短期记忆网络（LSTM）

### 门控记忆元

这段是在讲 LSTM 相比 GRU 多引入了一个更明确的“长期记忆通道”——记忆元 $C_t$。

可以先把 LSTM 想成有两条状态：

```text
h_t：当前对外使用的隐藏状态
C_t：内部长期记忆
```

其中 $C_t$ 更像“长期存储”，而 $h_t$ 更像“当前时刻暴露出来的工作状态”。

LSTM 用三个门控制 $C_t$：

- 输入门：决定“当前新信息写进去多少”
- 遗忘门：决定“旧记忆保留多少”
- 输出门：决定“当前记忆有多少暴露成隐藏状态 $h_t$”

可以直观理解成：

```text
旧记忆 C_{t-1}
   ↓
遗忘门：删掉一部分
   +
输入门：写入一些新信息
   ↓
得到新记忆 C_t
   ↓
输出门：决定展示多少
   ↓
隐藏状态 h_t
```

所以 LSTM 的核心就是：

> 把“长期记忆 $C_t$”单独拿出来，再用三个门分别控制删、写、读。

这也是它比普通 RNN 更容易保存长期信息的原因。

### 输入门、忘记门和输出门

这页是在讲：LSTM 的三个门是怎么“算出来”的。

在时间步 $t$，LSTM 手里有两样信息：

- 当前输入 $X_t$
- 上一时刻的隐藏状态 $H_{t-1}$

然后用这两样东西，分别计算三个门：

$I_t=\sigma(X_tW_{xi}+H_{t-1}W_{hi}+b_i)$$F_t=\sigma(X_tW_{xf}+H_{t-1}W_{hf}+b_f)$$O_t=\sigma(X_tW_{xo}+H_{t-1}W_{ho}+b_o)$

分别是：

- $I_t$：输入门，决定新信息写入多少
- $F_t$：遗忘门，决定旧记忆保留多少
- $O_t$：输出门，决定内部记忆对外暴露多少

为什么三个门输入都是 $X_t$ 和 $H_{t-1}$，却能做不同事情？

因为它们有完全不同的权重：

```text
输入门：自己的 W_i
遗忘门：自己的 W_f
输出门：自己的 W_o
```

这些权重都是训练出来的。

最后都经过 sigmoid，所以门值落在 0～1：

```text
≈ 0 → 基本关闭
≈ 1 → 基本打开
中间值 → 部分通过
```

比如遗忘门某一维：

$F_t=0.9$

就可以粗略理解成：

> 这一维旧记忆保留 90%。

注意这一页还只是“算三个门的开度”，还没有真正执行“忘、写、读”。下一步才会用这三个门去更新记忆元 $C_t$ 和隐藏状态 $H_t$。

一句话：

> LSTM 先根据“当前输入 + 过去状态”，用三个独立的小网络算出三个 0～1 的门值，再用这些门控制记忆的删除、写入和输出。

### 候选记忆元

这里讲的是 LSTM 在真正更新长期记忆之前，先算出一份“候选新记忆”。

核心公式：

$\tilde C_t = \tanh( X_tW_{xc} + H_{t-1}W_{hc} + b_c )$

直觉上：

> 根据“当前输入 $X_t$”和“上一时刻隐藏状态 $H_{t-1}$”，先生成一份“现在可能值得记住的新信息”。

这里的 $\tilde C_t$ 还不是真正写进长期记忆 $C_t$ 的内容，所以叫“候选记忆”。

例如当前输入是：

```text
“今天下雨”
```

结合之前的上下文 $H_{t-1}$，模型可能生成一份候选信息：

```text
“天气发生了变化”
```

但这份信息到底要不要写进长期记忆、写多少，要由后面的输入门 $I_t$ 决定。

为什么用 tanh？

因为候选记忆不是“开关”，而是实际的信息内容，所以需要既可以为正，也可以为负：

$-1 < \tilde C_t < 1$

而前面的三个门用 sigmoid，是因为它们表示“通过比例”：

$0

所以可以这样记：

```text
sigmoid 门：
决定“多少信息通过”

tanh 候选记忆：
决定“要写入什么信息”
```

因此现在 LSTM 已经算出了四样东西：

- $F_t$：旧记忆留多少
- $I_t$：新记忆写多少
- $\tilde C_t$：准备写入什么新内容
- $O_t$：最终向外输出多少

下一步就是把 $F_t$、$I_t$、$\tilde C_t$ 真正组合成新的记忆元 $C_t$。

### 这里旧记忆是隐藏状态吗？“新记忆写多少”又是什么意思？C_t的“准备写入什么新内容”又是向哪里写入？新内容指代新的隐藏状态吗？

这里要把 LSTM 里的两个“状态”彻底区分开：

- $C_t$：记忆元 / cell state，负责长期记忆
- $H_t$：隐藏状态 / hidden state，负责当前时刻对外使用的表示

所以你第一个问题：旧记忆不是 $H_{t-1}$，而主要是上一时刻的记忆元 $C_{t-1}$。

LSTM 更新长期记忆的核心公式是：

$C_t = F_t\odot C_{t-1} + I_t\odot \tilde C_t$

直觉上：

```text
旧长期记忆 C_{t-1}
      ↓
遗忘门 F_t：保留多少
      ↓
保留下来的旧记忆
      +
候选新记忆 C̃_t
      ↓
输入门 I_t：写入多少
      ↓
新的长期记忆 C_t
```

所以“新记忆写多少”指的是：

> 候选记忆 $\tilde C_t$ 有多少真正写进长期记忆 $C_t$。

例如某一维：

$I_t=0.2$

那么候选新信息只有 20% 被写入。

而“准备写入什么新内容”里的新内容，就是 $\tilde C_t$。它不是新的隐藏状态，而是一份“候选长期记忆”。

$\tilde C_t = \tanh(X_tW_{xc}+H_{t-1}W_{hc}+b_c)$

它根据当前输入 $X_t$ 和旧隐藏状态 $H_{t-1}$ 算出来。

最后，新的长期记忆 $C_t$ 算完后，才生成新的隐藏状态：

$H_t = O_t\odot\tanh(C_t)$

所以整个顺序是：

```text
X_t + H_{t-1}
      ↓
生成候选记忆 C̃_t

C_{t-1}
↓ 遗忘门
保留部分旧记忆

C̃_t
↓ 输入门
写入部分新记忆

两者相加
↓
C_t   ← 新的长期记忆
↓ 输出门
H_t   ← 新的隐藏状态
```

一句话区分：

> $C_t$ 是“内部长期记忆”，$H_t$ 是“从长期记忆中取出来、当前时刻对外使用的表示”。
