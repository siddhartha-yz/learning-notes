这一节就讲 3 个东西：

1. `main` 函数

```cpp
int main() {
    return 0;
}
```

- 程序从 `main` 开始执行。
- 一个程序只能有一个 `main`。
- `int` 表示 `main` 最后返回整数，`return 0` 通常表示正常结束。

1. 字符与字符串

```cpp
'A'          // 字符
"hello"      // 字符串
""           // 空字符串
```

记忆：**单引号 = 一个字符，双引号 = 字符串。**

1. 头文件

```cpp
#include <iostream>
```

可以把头文件理解成「工具箱」。

`iostream` 提供输入输出相关工具，例如：

```cpp
std::cout
std::cin
```

C++ 头文件通常没有 `.h`：

```cpp
#include <iostream>
#include <cmath>
```

C 时代常见：

```cpp
#include <stdio.h>
#include <math.h>
```

对应的 C++ 风格通常是：

```cpp
#include <cstdio>
#include <cmath>
```

一句话记忆：

> `main` 是入口，`"..."` 是字符串，`#include` 是把工具箱拿进来。





这一节核心就 4 个：

1. `cin` / `cout`

```cpp
cin >> x;      // 输入
cout << x;     // 输出
```

记忆：`>>` 往变量里塞，`<<` 往屏幕上送。

1. `endl`

```cpp
cout << x << endl;
```

作用：换行，并刷新输出缓冲区。

1. 命名空间

```cpp
using namespace std;
```

`cout`、`cin`、`endl` 都在 `std` 里。

也可以直接写：

```cpp
std::cout << "hello";
```

命名空间的本质：**隔离名字，避免重名冲突。**

1. 注释

```cpp
// 单行注释

/*
多行注释
*/
```

注释不会参与编译，也可以暂时屏蔽代码。

一句话记忆：

> `cin` 输入，`cout` 输出，`endl` 换行，`std` 管标准库名字，注释给人看不给编译器看。





这节讲的是 C++ 的基础数据类型。   

```
char        // 字符
short       // 短整数
int         // 整数
long
long long   // 更大的整数

float       // 单精度小数
double      // 双精度小数
long double // 更高精度小数

bool        // true / false
```

几个重点：

- `char` 存字符，本质上存的是字符对应的 ASCII 编码。比如 `'A'=65`，`'a'=97`，大小写相差 32。   粘贴的文本 (1)
- 整数根据范围分成 `short / int / long / long long`。   粘贴的文本 (1)
- 小数主要用 `float / double / long double`。普通 `3.14` 默认是 `double`，`3.14f` 才是 `float`。   粘贴的文本 (1)
- 科学计数法：`1e5` 就是 $1\times10^5$。   粘贴的文本 (1)
- `bool` 表示真假：`true / false`；条件判断里 `0` 是假，非 `0` 是真。   粘贴的文本 (1)

一句话：

> 数据类型就是告诉编译器：这个变量里装的到底是字符、整数、小数，还是真假。





这节核心：`signed` 和 `unsigned`。

```
signed int      // 有符号整数：可正可负
unsigned int    // 无符号整数：只能 >= 0
```

几个重点：

- `int` 默认就是 `signed int`，所以 `signed` 通常省略。
- `unsigned` 不能省略。
- 同样位数下，`unsigned` 因为不用表示负数，所以正数范围更大。
- `short / int / long / long long / char` 都可以被 `signed / unsigned` 修饰。
- 但 `char` 单独写时到底是 `signed char` 还是 `unsigned char`，取决于编译器，不能想当然。

例如：

```
unsigned int x = 10;   // 正常
unsigned int x = -10;  // 会被解释成很大的正数，不是 -10
```

一句话记忆：

> 可能出现负数就用 `signed`；确定永远非负，可以用 `unsigned`。











这节核心：**数据类型大小决定能存多大的数。**

```
sizeof(int)   // 查看类型/变量占多少字节
sizeof(x)
```

单位关系：

```
1 Byte = 8 bit
```

视频演示环境下：

```
char         1B
bool         1B
short        2B
int          4B
long         4B
long long    8B
float        4B
double       8B
long double 16B
```

竞赛最重要记两个：

```
int       ≈ -2.1×10^9 ~ 2.1×10^9
long long ≈ -9.2×10^18 ~ 9.2×10^18
```

所以：

> 数据范围在 $10^9$ 左右 → `int`；可能超过 `int` → 优先考虑 `long long`。

最大最小值可以通过 `<climits>` 里的 `INT_MAX`、`INT_MIN`、`LLONG_MAX` 等获取。

一句话：**类型越大 → 占内存通常越多 → 能表示的数通常越大；做算法题先看数据范围再选类型。**













这节核心：`typedef` 给类型起别名。

```
typedef unsigned long long ULL;
```

之后：

```
ULL x;
```

就等价于：

```
unsigned long long x;
```

作用：

- 缩短复杂类型名
- 提高写代码速度
- 竞赛里常见

常见写法：

```
typedef unsigned int uint;
typedef long long LL;
typedef unsigned long long ULL;
```

一句话：

> `typedef` 不创造新类型，只是给已有类型换个更短的名字。









这节核心：**变量 = 可以改变的值。**    

创建变量：

```
int age;
double weight;
```

初始化：

```
int x = 10;   // 创建时给值，叫初始化
x = 20;       // 之后改值，叫赋值
```

变量命名规则：只能由字母、数字、下划线组成，不能数字开头，不能用关键字，而且区分大小写。   

变量分两种：

```
int g = 10;   // 全局变量

int main() {
    int x = 1;   // 局部变量
}
```

- 全局变量：作用范围广。
- 局部变量：只在所在 `{}` 范围内有效。
- 同名时，局部变量优先。   

初始化区别：

- 局部变量不初始化 → 值不确定，**不要直接使用**。
- 全局变量不初始化 → 默认初始化为 `0`。   

竞赛里为了方便，常用全局变量；工程开发一般尽量少用全局变量。  

一句话：

> `类型 + 变量名` 创建变量；创建时给值叫初始化；局部变量一定注意初始化。









这节核心：C++ 的三种常量。

1. 字面常量

```
100
3.14
'A'
```

直接写出来的固定值。

整数还能写成不同进制：

```
22      // 十进制
026     // 八进制
0x16    // 十六进制
```

1. `#define` 常量

```
#define PI 3.14159
```

本质：编译前把 `PI` 直接替换成 `3.14159`。

注意：

- 不写类型
- 后面没有 `;`

1. `const` 常量

```
const double PI = 3.14159;
```

特点：

- 有明确类型
- 初始化后不能修改
- C++ 中更常用、更推荐

常量名习惯全大写：

```
const int MAXN = 1000;
```

一句话：

> 字面常量是直接写值，`#define` 是文本替换，`const` 是有类型的只读变量；C++ 优先用 `const`。









这节核心：**算术运算 + 整数除法 + 溢出。**

```
+   // 加
-   // 减
*   // 乘
/   // 除
%   // 取模（余数）
```

重点：

```
7 / 2      // 3，整数除法
7.0 / 2    // 3.5，有浮点数参与
7 % 2      // 1
```

- `/` 的除数不能是 `0`
- `%` 两边必须是整数
- 想得到小数：除法两边至少一个是浮点数

```
a * 1.0 / b
```

负数取模：结果符号跟左边操作数一致：

```
11 % -5   // 1
-11 % 5   // -1
```

最后一个大坑：**数值溢出**。

类型能表示的范围有限，超过范围后结果会异常。因此竞赛里一定先看数据范围：

> 数可能很大时，优先考虑 `long long`。









这节核心：**赋值操作符 `=` 和复合赋值。**

```
int a = 10;  // 初始化
a = 20;      // 赋值
```

注意：`=` 是把**右边的值赋给左边**。

连续赋值：

```
c = b = a + 2;
```

等价于：

```
b = a + 2;
c = b;
```

复合赋值：

```
a += 3;   // a = a + 3
a -= 3;   // a = a - 3
a *= 3;
a /= 3;
a %= 3;
```

交换两个变量不能直接：

```
a = b;
b = a;   // 错，会丢掉原来的 a
```

要用临时变量：

```
int t = a;
a = b;
b = t;
```

一句话：

> `=` 是赋值，`+= -= *= /= %=` 是简写；交换两个变量要先用临时变量保存一个值。











这节核心：**不同数据类型混合时，会发生类型转换。**

三种情况：

1. 混合运算自动转换

```
char / short  ->  int
```

例如：

```
char a = 'A';
int b = 10;
a + b   // a 先提升成 int
```

较大的类型混合时，通常往“更大/更精确”的类型转：

```
int + double  ->  double
```

1. 赋值时转换

```
double x = 3.14;
int a = x;     // 变成 3，小数部分丢掉
```

小类型 → 大类型：通常直接转。

大类型 → 小类型：可能发生**截断/数据丢失**。

1. 强制类型转换

```
int a = (int)3.14;   // 3
```

作用：手动要求把一个值临时转换成指定类型。

一句话：

> 混合运算会自动“统一类型”；大类型塞进小类型可能丢数据；强制转换就是你手动指定“把它当成某种类型”。
